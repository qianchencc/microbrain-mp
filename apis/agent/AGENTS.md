# Agent 请求缓存

- `requestJson` 保留原始请求/错误语义。只有 `index.js` 中显式接入 `companyRead` 的概览、目录、逐日与期间统计复用缓存，不能把所有 GET 都缓存。
- `company-read-cache.mjs` 的作用域来自不可逆身份键（Token + 园区）；内存60秒、最多40项，过期快照最多5分钟只供UI占位，正常read不能返回过期结果。错误与截断不缓存，401/403清空整组；代际校验阻止清理前的请求重新写回。
- 确认/取消设备或任务前后清理；普通对话、已读操作、草案勾选不清缓存。强制刷新绕过已完成结果，但可等待同一在途新读取。
- 控制、执行状态/回执、任务列表、会话、报告下载、短时效视频地址走实时请求，不复用此缓存。服务器执行前权限核验不受前端缓存影响。
