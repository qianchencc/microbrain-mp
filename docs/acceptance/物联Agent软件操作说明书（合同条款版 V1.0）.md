# 物联 Agent 软件操作说明书

> 本说明书面向使用人员，说明物联 Agent 的功能范围、进入方式与操作方法。

---

## 第 1 章 产品概述与使用入口

### 1.1 产品概述

物联 Agent 是小程序内的一个页面。用户通过仪表盘快速了解公司物联设备情况，告警情况以及基础能耗情况。并通过自然语言对话完成设备检索、设备控制、能耗查询、监控查看、告警查询与定时任务安排。

系统包含两个助手，适用范围不同：

| 助手 | 适用人员 | 功能范围 |
| --- | --- | --- |
| 物联助手（公司） | 设施管理人员 | 全公司设备查询与控制、能耗统计、安全告警、监控视频、定时任务 |
| 办公室 Agent | 普通员工 | 本人办公区域内的设备查询、控制与定时任务 |

两个助手均只显示**当前用户权限范围内的设备**，权限范围外的设备不可查询、不可控制。其中两个入口所依赖的权限范围并不相同，分别来自微脑中 智慧xx->角色配置，以及 我的办公室->地址元素->新增人员。

在使用中,公司Agent通常用于能耗分析、告警处理，大范围设备操作。由于缺少区域分类，因此对于个别设备的操作通常需要提供大致位置，通过检索以及追问来精确定位，可通过优化设备命名来提高检索命中概率。
而办公室Agent自带区域，因此通常不需要提供具体定位信息。

### 1.2 进入方式

1. 打开小程序并完成登录；
2. 在首页菜单中点击「物联助手」，进入总览页面；
3. 总览页面右下角的圆形按钮为公司助手入口，点击后展开对话面板；
4. 总览页面顶部标题栏的「办公室 ›」为办公室 Agent 入口。

【截图：首页「物联助手」菜单项】【截图：总览页（标注两个入口）】

### 1.3 总览页面说明

进入「物联助手」后默认显示精简模式：

- 页面顶部为状态指示灯：绿色表示正常，显示感叹号表示存在需关注的事项，指示灯下方给出文字说明；
- 指示灯下方为六个功能块：环境、用电、安全、任务、设备、通知。每个功能块显示一行状态与一行数据，点击可进入对应详情页；
- 页面右上角「精简 / 详细」用于切换显示模式，详细模式展示更多信息板块；
- 页面底部「直接问助手」用于打开公司助手对话面板。

## 第 2 章 设备检索与控制

### 2.1 设备检索

在对话中描述设备名称、别名或安装位置即可检索设备。示例：

#### 公司Agent

- 「26楼运营办公区的灯现在什么状态」
- 「26楼会议室空调开没开」

#### 办公室Agent

-  「办公室有几盏灯，哪几个开着」

检索范围限于当前用户的授权设备。当描述存在歧义或符合多台设备时，助手列出候选设备供用户选择，不自行猜测。

检索结果以模型回答呈现，显示设备清单与当前状态（开/关/在线/读数）。

### 2.2 空调控制

在对话中描述目标状态。示例：

#### 公司Agent

- 「把26楼会议室空调开到 24 度制冷」
- 「关掉26楼会议室空调」

#### 办公室Agent

- 「关下空调」

草案中将列出每台空调以及预期调整。长按设备卡片可完成自定义调整，参数包括：电源、模式、风速、温度。温度设置超出设备允许范围（16–30℃）时无法提交并给出提示，无效指令不会下发。

在确认草案前可对同类设备统一调整参数，也可逐台修改后执行。

### 2.3 照明与门禁控制

操作方法同空调控制。示例：「关闭这些26楼的各办公区的照明和空调，保留过道区域照明」「开一下26楼大门」。

门禁开门等操作必须先经确认界面核对设备清单，点击「执行操作」后指令方可下发；未确认时不执行任何操作。

### 2.4 批量操作与执行确认

描述操作范围即可发起批量控制。示例：「关掉三楼整层照明」「这层除了会议室都关灯」。

- 系统生成操作预览清单，列明拟执行台数、排除台数及已符合目标状态无需操作的台数；
- 清单按楼层位置分组显示，支持逐台勾选、搜索与排除；
- 点击「执行操作」确认执行；点击「取消」则不执行任何操作。

预览清单具有有效时限，超时后界面显示「核验已过期」，须重新核验后方可执行。

### 2.5 执行结果说明

执行完成后，每个操作给出统一结果，含义如下：

| 显示 | 含义 |
| --- | --- |
| 已完成 / 平台回读 X℃ | 已取得设备实测数据，确认操作已生效 |
| 已下发 | 指令已被受理，平台暂未返回实测数据，以现场实际状态为准 |
| 部分完成 / 失败 | 部分或全部设备未执行成功，点击「查看原因」查看每台设备的具体说明 |
| 无需操作 | 核验时设备已处于目标状态，未重复下发指令 |

每次操作从对话、确认清单到执行记录全程留存，可在任务记录中回查。

## 第 3 章 能耗查询与分析

### 3.1 能耗数据

系统接入电表计量设备及平台能耗数据，统一计量口径：单位为「度」，按每日 08:00 为昨日边界计算。

其中甲方提供的接口中未见水表设备。

### 3.2 能耗监测

总览页面「用电」功能块显示最近一日用电量及环比涨跌幅，点击进入能耗面板后可进行以下操作：

- 按日查看每日用电量，选择任意日期查看当日构成（各电表用电量及占比）；
- 用电偏高时，总览页「用电」块与状态灯显示「注意」；
- 数据缺失时如实显示「—」或「暂不可用」，未以零值或旧数据替代。

### 3.3 能耗统计与对比

能耗统计可通过以下两种方式获取，结果一致：

- 界面操作：能耗面板 →「时间对比」→ 选择「本月 / 近 30 天 / 近 7 天 / 单日 / 自定义」；
- 对话查询：直接提问，如「分析一下2026年8月至9月的几周的公司能耗，并给出节能计划，以及需要注意的部门」。

统计结果显示本期与对照期用电量、增减幅度及逐表对比（按增量排序）。当两期覆盖的表数或层级不同时，自动按单台平均计算，保证口径可比。

### 3.4 能耗报表

在对话中描述报表需求，如「公司本月的能耗**报告**」，可在报告组件中点击「下载 PDF / 导出表格」。

- 报表包含统计口径说明、各电表数据依据与覆盖情况，可存档、分发；
- 日报、月报等周期性报表可通过定时任务自动生成（见第 5 章），完成后在「通知中心」中查收。
- 常规物联任务中说明报表需求即可生成报告附件，仅在公司Agent中可用。

### 3.5 对话查询能耗

能耗查询与设备控制使用同一对话入口。示例：

- 「统计一下最近能耗情况」
- 「分析本月公司夜间用电，找出夜间用电较多的部门和位置，给出节能建议」

助手返回数据卡片与图表。卡片可交互，可查看明细，也可继续追问。

## 第 4 章 视频监控与安全告警

### 4.1 实时视频查看

对助手描述摄像头位置，如「看看大堂摄像头」；或在台账、设备页面中选择监控设备，点击视频块的「看直播」。

- 视频流即点即开；摄像头离线或状态未知时如实显示；
- 仅可查看当前用户权限范围内的摄像头。

### 4.2 录像回放

对助手描述回放需求，如「回放昨天下午两点前后26楼运营办公区的录像」，在观看卡片上点击「查看这段录像」，填写录像起止时间后播放。

【截图：录像回放表单】

### 4.3 人员统计

甲方暂未提供相应接口。

### 4.4 安全告警台账

总览页面「安全」功能块显示最近告警记录，点击进入完整台账。

- 台账按类型分类：烟感、燃气、水浸，支持按日期区间筛选；
- 每条记录显示告警时间与设备名称，点击查看详情：事件来源、当前设备名称与安装位置（未经核验的信息会明确标注）；
- 也可在对话中直接查询，如「最近有哪些消防告警」「整理一下最近一周的告警并生成报告」。

### 4.5 告警关联监控查询

系统中可检索与告警设备同一地点或同楼层的摄像头，并提供告警时段的回放和直播卡片。

- 在告警详情页点击「按当前位置查找监控」，系统检索候选摄像头，生成该时间点前后 15 分钟的录像回放卡片。
- 在告警详情页点击底部「引用到对话」，编写消息后发送，由agent检索候选摄像头并产出录像回放卡片，并提供处理建议。

### 4.6 安全约束

- 告警与视频数据为只读
- 告警类问题的答复中，助手给出核实与跟进建议，但不声称已通知或已处置；
- 涉及设备动作的操作（含自动化任务）均保留人工确认与暂停、取消能力（见 5.7）。

## 第 5 章 定时与自动化任务

### 5.1 设备清单

总览页面「设备」功能块显示全量设备清单；详细模式下点击某一类别（环境/能耗/安全/空调/照明/门禁/视频）查看该类设备。

- 清单按设备类型与安装位置分组。
- 设备名称、位置与可执行操作在清单中统一展示，同时作为对话检索的基础数据。

### 5.2 一次性定时任务

在对话中描述执行时间与动作。示例：

- 「明天 18:00 关闭本层照明」
- 「今天下午到明早，每隔半小时查看一次机房温度」

系统生成任务确认单，列明执行时间、设备范围与动作。确认后点击「创建任务」；点击「放弃」则不创建。创建后任务可在首页‘任务管理’中取消。

### 5.3 周期计划

在对话中描述重复规则。示例：「每个工作日 17:30 关闭26楼运营办公区的灯」「每天上午 9 点生成公司昨日能耗简报」。

- 周期计划到点自动生成当天的执行任务；
- 「任务中心 → 周期安排」集中显示各计划的重复规则、下一次执行时间与最近一次执行结果；
- 支持启用和关闭、跳过本次与取消全部(删除该周期任务)。

### 5.4 条件触发任务

在对话中描述「条件 + 动作」。示例：

- 「每 30 分钟检查26楼会议室空调，低于26℃ 就调到 26℃」

系统按每 15 / 30 / 60 分钟间隔展开检查点，仅在条件满足时执行动作。

空调巡检类任务可生成检查报告与节能估算。估算结果附计算依据。

### 5.5 任务查看与管理

任务在「任务中心」中统一管理，提供三个视图：

- **全部任务**：按日期分组，分列待执行与执行结果；
- **日历**：月视图展示，异常任务以橙点标记，点击日期查看当日任务；
- **周期安排**：周期计划列表及启停操作。

办公室端另设「区域工作台」，按区域以时间轴形式展示当日任务，包含任务时间、安排人与执行状态。

打开任务详情可查看执行阶段、各设备执行结果、完整操作记录与报告；支持取消任务，以及对任务发起引用追问。

### 5.6 任务结果与报告

- 任务执行完毕后，结果消息进入「通知」中心，打开后自动标记为已读；
- 报告长期保存，可随时查看、下载 PDF、导出表格或引用追问；
- 任务状态与第 2 章一致（已完成 / 已下发 / 部分完成 / 失败并附原因）。

### 5.7 自动化任务的安全约束

- 全部自动化任务在创建前均产出确认单，必须手动确认才可创建；
- 任务仅能覆盖当前用户权限范围内的设备与操作；
- 执行中或已建立的任务可随时暂停、跳过或取消，取消后不影响已执行结果；
- 存在异常的任务在日历（橙点）、区域标记（黄点）与通知中提示，便于人工处理。

## 第 6 章 身份、权限与交付说明

### 6.1 身份与权限

- 沿用小程序现有的登录与组织确权体系，Agent 不增加用户原本没有的设备权限；
- 设备范围按用户划分：同一指令下，不同身份的用户仅看到本人权限内的设备；
- 切换账号后，对话记录、设备清单、任务与未读通知按新身份重新加载。

### 6.2 安全审计与风险控制

- 对话记录、确认单与执行记录全程留存，可供回查；
- 操作必须经人工确认，超时的失效确认单不可执行；

### 6.3 使用入口与集成说明

- 交付形式为小程序内嵌「物联助手」入口，无需安装独立应用；

### A. 常用指令示例

| 使用目的 | 指令示例 |
| --- | --- |
| 查询设备 | 「三楼东侧的灯现在什么状态」 |
| 控制设备 | 「把会议室空调开到 24 度」「关掉本层照明」 |
| 查看能耗 | 「本月用电多少」「上周哪天用电最多」 |
| 查看监控 | 「看看大堂摄像头」「回放昨天 14 点东侧的录像」 |
| 查询告警 | 「最近有哪些消防告警」「整理最近一周的告警并生成报告」 |
| 创建任务 | 「每天 18:00 关本层照明」「每半小时检查机房空调」 |
| 管理任务 | 「取消明天 18 点的关灯任务」「暂停每天的巡检计划」 |

### B. 可能的常见问题

- **查找不到某台设备？** 该设备超出当前用户权限范围，或账号刚切换后清单已更新，或设备命名有误，与提供的位置不相关。
- **显示「已下发」但设备状态未变？** 指令已受理并执行，由于部分设备操作缺少回读，具体情况以现场实际状态为准。
- **能耗显示「—」或「不可计算」？** 目标时段期间采样缺失，或数据尚未加载。
- **显示「核验已过期」？** 确认单已超过有效时间，重新核验后再次确认即可，或重新要求智能体给出。

### C. 用语说明

- 「已下发」：指令已被平台受理，尚未返回实测数据；
- 「平台回读」：平台返回的设备实测数据；
- 「确认单」：执行/创建任务前列出的操作清单，确认后才操作/创建；
- 页面列表数据为约 1 分钟内的缓存结果，可手动刷新获取最新数据。
