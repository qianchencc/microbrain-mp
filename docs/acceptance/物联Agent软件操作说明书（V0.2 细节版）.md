## 1 概述

### 1.1 系统简介

物联 Agent 是嵌入客户小程序的物联网智能体，由三部分组成：

| 组成 | 入口路径 | 定位 |
| --- | --- | --- |
| 物联助手仪表盘 | `pages/agent/dashboard` | 公司端总览 + 公司 Agent（右下角浮层） |
| 办公室 Agent 页 | `pages/agent/index` | 员工端对话页（标题「办公室 Agent」） |
| 区域工作台 | `pages/agent/region` | 办公室端的任务时间轴与设备浏览 |

- 公司 Agent 与办公室 Agent 是两套独立身份与设备范围：公司端面向设施管理人员，覆盖微脑目录下的环境/计量/安全/空调/照明/门禁/视频设备；办公室端面向员工，覆盖其办公区域的授权设备。
- 两端共用同一套会话、确认、任务与报告机制。
- 【截图：仪表盘首屏（精简模式）】

### 1.2 运行环境与前置条件

- 微信小程序（正式版走客户网关，开发版走云端 Agent API），需完成微信登录与组织确权。
- 设备可见范围 = 当前登录用户的**授权设备范围**（Authorized Device Scope）：范围外的设备在对话与列表中均不可见。
- 切换身份或园区后，Agent 会话、设备目录、任务与未读数全部按新身份重新加载。
- 【待补：正式版/体验版/开发版环境差异与适用人群】

### 1.3 术语约定

| 术语 | 含义 |
| --- | --- |
| 草案 / 操作卡 | 设备控制执行前的待确认卡片，点「执行操作」后才下发指令 |
| 提案 / 任务卡 | 定时或周期任务的待确认卡片，点「创建任务」后才登记 |
| 任务（Task） | 一次性或到点生成的具体执行单 |
| 周期计划（Plan/重复安排） | 按日/周重复的计划，到点生成实际 Task |
| 检查点 | 条件类周期任务由服务端展开的执行时刻（15/30/60 分钟间隔） |
| 台账 | 安全告警事件记录（烟感/燃气/水浸等类别） |
| 快照 | 概览/目录/能耗/任务列表的短时缓存数据（约 60 秒） |
| 回读 | 平台返回的设备实测数据；区别于「平台影子值」（可能为指令回声） |
| 引用 | 把安全事件/环境窗口/任务/报告带进对话的上下文标记，发送时服务端重新核验 |
| 虚拟发生 | 周期计划未到执行时间的未来实例，仅用于展示与预览 |

## 2 基础能力指引（通用操作）

### 2.1 登录与身份

- 功能说明：Agent 依赖小程序登录态；进入 Agent 页面前会等待会话与园区上下文就绪。
- 入口：小程序首页 → 微信登录 →（需要时在「我的 → 组织确权」完成确权）。
- 操作步骤：【待补：登录 → 确权 → 返回首页的具体操作】
- 结果与判读：连接建立后头部状态显示「服务在线」；未就绪显示「正在连接」，失败显示错误提示。
- 注意事项：页面与组件不直接接触 Token；身份失效会显示「当前登录状态不可用，请稍后重试」。切换身份/园区会清空旧会话、目录、任务与编辑状态。

### 2.2 入口导航

- 功能说明：物联 Agent 的唯一固定入口是服务首页菜单中的单行「物联助手」（玉漆头像图标）。
- 操作步骤：
  1. 服务首页点击「物联助手」→ 进入仪表盘；
  2. 仪表盘标题栏右侧「办公室 ›」按钮 → 进入办公室 Agent 页；
  3. 办公室 Agent 页头部「工作台」→ 进入区域工作台。
- 结果与判读：【截图：首页菜单项 / 仪表盘标题栏 / 办公室页头部】
- 注意事项：办公室 Agent 没有独立菜单入口，只能从仪表盘标题栏进入；导航栏「‹」按页面历史返回，默认回到「服务首页/总览」。

### 2.3 对话基础操作

- 功能说明：双端共用同一会话界面（办公室为整页，公司为浮层）。
- 操作步骤：
  1. **发消息**：底部输入框输入文字 → 点「发送」；运行中按钮变为「停止回答」。
  2. **推荐问法**：公司端空会话欢迎区显示 4 条固定问法（统计能耗/夜间耗电异常/设定时任务/整理告警出报告），点击只填入输入框、需再点发送；首轮落位后消失。办公室端无此入口。
  3. **语音输入**：点输入框旁「切换语音输入」→「按住说话，上滑取消」→ 松开发送；识别失败提示「语音识别失败，请重试或使用文字输入」，未开通时提示使用文字输入。
  4. **编辑/重试**：点按自己最近一条消息出「编辑/重试」；编辑时输入区显示「正在编辑消息」，可「取消编辑」；重试沿用原消息重新发送。
  5. **清空会话**：头部菜单「清除当前会话」（无会话可清时提示「暂无可清除的会话」）。
- 结果与判读：答复流式展示；工具过程折叠为「处理记录」中的「检索思路」行（如「检索设备候选」「核验设备能力」「查询设备状态」「生成操作草案」）；卡片可先落位、正文终稿随后。
- 注意事项：运行中收起/切页不中止任务；未入服务端会话的失败轮可直接重试；【截图：输入区 / 语音态 / 处理记录展开】

### 2.4 引用机制

- 功能说明：把一条业务记录带进对话，使 Agent 围绕它回答；引用条显示在输入区上方。
- 入口与形式：
  - **安全事件引用**：台账详情页「引用到对话」→ 引用条显示「已关联原记录」；事件身份 = 台账类别 + 事件 ID。
  - **环境窗口引用**：环境历史页「向公司 Agent 询问此期间」→ 结构化 `environment_window` 引用（from/to 取服务端窗口）。
  - **任务/计划引用**：任务详情「引用任务并询问」、计划行「询问这个计划」→ 固定身份引用。
  - **报告引用**：报告预览页「引用本报告」→ 追问沿用保存事实。
  - **客户告警引用**：外部消息卡片深链 → 显示「客户告警引用」chip 并预填问题。
- 操作步骤：在详情页点引用 → 输入区出现引用条 →（可再点「移除引用」或保留）→ 输入问题发送。
- 结果与判读：发送时服务端按当前授权**重新读取该记录的最新事实**；引用条下方提示「发送时读取同一记录的最新事实，可直接询问结果或说明修改意图」。
- 注意事项：空草稿会预填问题，已有草稿只询问是否替换、不清掉引用；引用不代表操作授权；不会自动发送。
- 【截图：引用条】

### 2.5 确认机制

任何设备控制、任务创建/修改/取消都必须先出卡片、人工确认，Agent 不会自行执行。

- **操作草案卡（设备控制）**：
  - 显示「待确认操作」、设备清单（按位置分组概览）、拟执行/不动标记、「已选 N 项」。
  - 可点「查看全部」打开草案面板：搜索设备、勾选/排除、空调参数长按调整（电源/模式/风速/目标温度，可「应用到全部同类设备」）。
  - 确认：「执行操作」→「正在执行，请稍候」→ 结果页；取消：「取消」→「操作已取消，未执行」。
  - 异常态：「核验已过期，未执行」（需「重新核验」后再确认）；「执行中断，部分指令可能已下发，以设备实际状态为准」；「核验时已达到目标，未发送控制指令」（无需操作）。
- **任务提案卡（定时/周期）**：
  - 显示范围、排除台数、预检结果（无需调整/需要调整/暂未读到状态）、下一次执行/下一次检查。
  - 确认：「创建任务」/「创建重复安排」→「正在创建」→ 已创建；放弃：「放弃」→「已放弃」。
  - 状态流转：待确认 → 已创建/已放弃/已过期/已取消。
- **任务变更卡（修改/暂停/跳过/删除）**：
  - 形态：调整安排 / 暂停重复安排 / 恢复重复安排 / 删除任务或重复安排 / 跳过本次安排。
  - 每卡带作用域选项（本任务/仅本次/整个周期）与说明（如「确认后暂停重复，以后不再执行；已经生成的任务继续」）。
  - 确认：「确认修改/确认暂停/确认跳过/确认删除」→「已确认」。
- **取消提案卡**：列表先列出待取消的准确任务，确认后调用取消；放弃/新消息/过期只退役提案。
- 结果与判读：重复确认只会回放结果、不重复执行；旧卡随新消息失效，不能拿已执行操作并入新草案。
- 【截图：操作卡 / 草案面板 / 任务卡 / 变更卡】

### 2.6 结果与失败判读

- 结果口径（统一）：
  - **已下发**：指令已受理但平台未回传实测——不显示「已完成」，也不算异常；
  - **已完成 / 平台回读**：有回传数据支撑（如「已下发调到 26℃ · 平台回读 25.5℃」）；
  - **失败/部分完成/错过/中断**：标异常，卡片与列表显示「查看原因」；
  - **无需操作/已检查**：只读或已满足目标的收口。
- 「查看原因」打开原因页：可滚动、可复制的原始原因文本（设备名 + 原因）；返回回到原任务。
- 注意事项：
  - 不要把指令目标当设备实测（调温目标是 X，「平台回读」才是实测；现场面板支持半度、协议上报整数，可能不一致）；
  - 「平台影子值」是协议回显，不一定是设备实测；
  - 授权/登录失效时失败原因显示「创建者登录已失效」；
  - 任务创建等待不代表已创建；待确认/已创建/已结束互斥。
- 【截图：结果卡 / 原因页】

### 2.7 通知与收件箱

- 功能说明：任务结束消息、执行摘要进入站内收件箱；Agent 头部与公司浮层 orb 显示未读角标。
- 操作步骤：
  1. 点头部收件箱图标（或仪表盘「通知」块）→ 通知中心；
  2. 筛选 tabs：全部 / 未读 / 已读；顶部「全部已读」「刷新」；
  3. 点单条「任务执行结果」→ 打开同源报告/任务 → 成功读取后自动标记已读。
- 结果与判读：未读数为 `N 条未读`（>99 显示 99+）；标记失败提示「暂时没能标记已读，请重试」；空列表显示「任务结束后，结果消息会出现在这里」。
- 注意事项：已读只作废通知快照；未读数读取失败时显示「暂不可用」而非「无未读」。
- 【截图：通知中心】

### 2.8 页面层级与返回

- 功能说明：所有详情（任务/设备/台账/报告/能耗）以底部 Sheet 打开；抽屉内是单层三级导航栈。
- 操作步骤：左侧「‹ 返回」退局部一层（如 设备时间轴 → 设备列表）；右侧「✕」关闭整层；微信原生返回逐层退。
- 结果与判读：Sheet 内导航标题随层切换（任务管理/任务详情/我的安排/重复安排…）。
- 注意事项：面板参数有未保存修改时，关闭前二次确认「放弃未保存的修改？」；确认失败的错误保留面板可重试。

## 3 页面与组件说明

### 3.1 物联助手仪表盘（pages/agent/dashboard）

#### 3.1.1 页面骨架

- 顶部导航：标题「物联助手」+ 分隔线 +「办公室 ›」按钮（打开办公室 Agent）。
- 问候行：左侧日期 +「你好，{姓名}」（姓名取个人信息实名，回退昵称/脱敏手机号）。
- 右侧操作：「精简/详细」分段切换（默认精简，偏好记忆，切换不重建数据）+ 圆形刷新按钮（读取中图标旋转）。
- 异常条：整页错误显示原因 +「重试」；部分数据失败显示「部分观测暂不可用 · 查看」。

#### 3.1.2 精简模式（默认）

- **状态灯**：中央圆盘汇总全局结论——正常绿盘 / 注意（`!`）/ 数据暂不可用 + 一句话结论与副文案；按环境、用电、安全注意项与各分区错误聚合。
- **2×2 + 2 状态块**（每块含图标、标签 pill、名称、状态、数值，点击进对应详情）：

| 块 | pill/状态取值 | 数值示例 | 点击去向 |
| --- | --- | --- | --- |
| 环 境 | 正常·舒适 / 注意·一般 / 暂不可用 | 如「26°C · 45%」 | 环境历史趋势 |
| 用 电 | 正常·平稳 / 注意·偏高 / 暂不可用 | 如「10月28日 1,234度 ↑5%」 | 能耗统计 |
| 安 全 | 正常·无告警（近30天）/ 注意·有记录 / 暂不可用 | 最近告警日期+类型 | 安全台账 |
| 任 务 | 空闲·0项 / 进行中·N项 / 暂不可用 | 下一项任务时间+名称 | 任务中心·全部任务 |
| 设 备 | 正常·N台·7类设备 / 暂不可用 | — | 全量设备目录抽屉 |
| 通 知 | 无未读 / N条未读 / 暂不可用 | 任务与报告 | 任务中心·通知中心 |

- 底部「直接问助手」卡片（示例文案：比如「上周哪天用电最多」）→ 展开公司 Agent 浮层。
- 注意事项：任务块与通知块并行加载、互不影响；安全块只反映最近一条台账是否在近 30 天内，不代表实时报警；用电差值仅在上一个完整计量日存在时给出，缺数显示「—」。

#### 3.1.3 详细模式

- **设备分类计数行**：环境/能耗/安全/空调/照明/门禁/视频七类数量；点某类打开该类的只读设备抽屉（`N 台`），未加载显示「—」。
- **环境传感器块**：实时读数格子（温度/湿度/CO₂/PM 等，随传感器配置），右上「趋势 ›」进环境历史。
- **能耗统计块**：
  - 横滑日柱条带：斜排日期、选中居中、拉满松手打开能耗面板、左端继续拉向前拼历史窗口；
  - 月度对比（MonthlyEnergyComparison）：每月 1 日 08:00 起算、每日 08:00/20:00 更新；显示「本期/对照」度数与增减幅度；点环比/同比整块展开逐表对比（按增量从高到低）。
- **安全台账块**：类型 chips（烟感/燃气/水浸/全部）筛选最近记录行（告警时间、设备名称、类型），「全部 N 条 ›」进台账。
- **自动化安排块**：近期任务/周期摘要（周几标题行 + 任务行，「还有 N 项」「查看所有任务 ›」），进任务中心。
- **双 Agent 入口**：公司浮层 orb（常驻右下角）+ 标题栏「办公室」。
- 注意事项：模式切换只切显示、不重取数据；各块失败独立显示重试。

### 3.2 公司 Agent 浮层（CompanyAgentFloat）

- 功能说明：常驻右下角圆形 orb；点开后为全宽底片对话面板（约至导航栏下沿）。
- 操作步骤：点 orb 展开 → 对话操作同 2.3–2.5；点遮罩或 orb 收起。
- 结果与判读：收起时——运行中 orb 显示运行环；有新消息显示未读角标；草稿与在途流保留。
- 注意事项：面板内打开的台账/任务 Sheet 浮在浮层之上；深链（告警/预填）首次展开时暂存送达。
- 【截图：orb 收起态 / 面板展开态】

### 3.3 办公室 Agent 页（pages/agent/index）

- 功能说明：员工端整页对话 + 头部功能区。
- 组成：
  - **AgentHeader**：「‹」返回 + 区域 chip（显示关注区域名，点开切换）+ 状态/名称 + 三个图标入口：工作台、任务、收件箱（未读角标）+ 会话菜单（前往工作台/任务管理/通知中心/清除当前会话）。
  - **会话主体**：同 3.4。
- 结果与判读：头部状态随连接变化（正在连接/服务在线/错误）；会话忙时入口保留可点（服务端以 409 为准防重复操作）。
- 【截图：头部区】

### 3.4 会话主体（AgentConversation 双端共用）

- 消息流按事件序渲染为有序条目：
  - **用户气泡**：自己发送的消息（可编辑/重试）。
  - **正文答复**：流式正文，终稿定色；无正文时只保留处理记录。
  - **处理记录**：工具调用折叠区「检索思路」，带状态（进行中/未完成/已跳过）与步骤摘要（如「正在修正检索范围…」）。
  - **观察卡**：只读事实块，按类型标签：环境/环境趋势/能耗/用电统计/用电对比/计量原始历史/计量结果/历史计量报告/电量周比较/视频/录像回放/相关监控/消防安全/告警台账/空调巡检/空调温度调整/报告附件。
  - **操作卡 / 任务卡 / 变更卡**：见 2.5。
  - **错误卡**：失败轮「这次暂未完成 · 重试回答」。
- 观察卡细节：
  - 视频块：在线绿点/离线灰点/未知警示 +「看直播」「查看这段录像」；
  - 环境块：读数格 + 来源标注（影子值/陈旧值标注）；
  - 能耗块：最新已知读数 + 读数时间；
  - 告警块：`N 条 · M 台`，部分结果标注「部分/分页未读完/部分类别未取得」；
  - 空调巡检块：逐台行「已下发调到 X℃ · 平台回读 Y℃」。
- 输入区：文本框 / 引用条（「已关联原记录 + 移除引用」）/ 语音切换 / 发送；编辑态显示「正在编辑消息 · 取消编辑」。
- 注意事项：答复中的卡片是只读事实呈现，需操作仍走确认卡。

### 3.5 区域工作台（pages/agent/region，仅办公室端）

- 功能说明：按「关注区域」查看任务时间轴与设备。
- 顶部：「‹」返回 + 区域 chip + 日期标题（「今天」或「X 月 X 日」）+ 右侧记录数（「N 条记录」/「任务加载中…」/「加载失败」）。
- **时间轴（RegionTimeline）**：
  - 纵向时间轴按天渲染，上下滚动自动向两侧扩展窗口；左侧时间刻度，右侧任务卡。
  - 左上浮动日期 chip（`X月X日`）+「展开设备日历」：点开月历选日（今天标「今天」），点日期定位到该日第一张任务卡。
  - 任务细卡：任务名（异常前置警示点）、设备头像组（+N 多余设备数）、创建者标记（按姓名散列着色，本人显示「我」）。
  - 状态标记：黄铜点 = 部分完成；红叉 = 失败/错过/中断；「已取消」保留可见；强调卡 = 执行中。

- **设备抽屉（RegionDeviceDrawer）**：单层三级导航栈——
  1. 设备列表：类型/位置/状态互斥分组 + 搜索（「搜索名称、位置或状态」）+ 手动「刷新设备状态」；
  2. 设备时间轴（DeviceTimelineView）：该设备的任务/操作记录按天浏览，左上角紧凑日历选日；
  3. 任务详情：共用任务详情宿主，可取消任务、看报告。

- 注意事项：开发版有「查看样例」开关显示本地演示数据（标注「本地演示记录 · 未写入设备或运行库」），正式版不出现。

## 4 办公室 Agent 业务能力

> 办公室端覆盖员工本人授权区域内的照明/空调/门禁等可控设备与环境/安全等只读设备；
> 无公司端的能耗统计、夜间收口等能力。

### 4.1 区域工作台（区域 chip 与关注区域）

- 功能说明：办公室端按「关注区域」组织任务与设备；区域 chip 显示当前区域名，黄铜点 = 有异常结果。
- 操作步骤：点区域 chip →「切换关注区域」选择 → 工作台/任务定位到该区域；未指明地点时 Agent 优先在此区域查找设备。
- 结果与判读：进入区域视为已查看最新结果；「暂无可用区域」「正在读取区域…」为等待态。
- 【截图：区域切换浮层】

### 4.2 设备查询与状态

- 场景示例：「三楼东侧的灯现在什么状态」「会议室空调开没开」。
- 操作步骤：对话提问 → Agent 检索授权目录（处理记录显示「检索设备候选」）→ 返回设备清单/状态卡；点设备行进详情或工作台设备抽屉查看。
- 结果与判读：开关类显示「已开启/已关闭/状态未知」；观察类显示在线状态/读数；状态卡附「刷新设备状态」。
- 注意事项：范围外设备返回找不到、不透露存在；名字不明确时 Agent 会列出真实候选请用户选择。

### 4.3 设备控制（照明 / 空调 / 门禁）

- 场景示例：「关掉本层照明」「把会议室空调调到 24 度」「开一下东侧门禁」。
- 操作步骤：提问 → 确认范围与参数 → 操作卡核对清单 →「执行操作」→ 看下发结果。
- 结果与判读：按 2.6 判读；范围操作可勾选排除；空调可在草案面板长按调电源/模式/风速/目标温度。
- 注意事项：所有控制必须先确认；核验过期需「重新核验」再确认。

### 4.4 定时与周期任务

- 场景示例：「明天 18:00 关闭本区域照明」「每个工作日 17:30 检查一遍办公室」「每天上午 9 点给我一份环境简报」「今天下午到明早每隔半小时看一下机房温度」。
- 操作步骤：描述时间与动作 → 任务卡核对（时间/范围/动作/预检）→「创建任务/创建重复安排」。
- 任务形态：
  - **一次性**：指定时刻执行一次；
  - **区间 + 检查点**：独立起止时间 + ≥1 个自由检查点，到点逐项执行、终点收口报告；
  - **周期计划**：每天/周一至周五/指定周几，到点生成实际 Task，「下一次执行/下一次检查」随窗口滚动。
- 结果与判读：到点执行产生结果与报告，进收件箱；周期计划在「周期安排」集中管理。
- 注意事项：只读任务（巡检/简报/统计）同样走提案确认但不产生控制；周期计划确认时若当天窗口已开始，从下一个检查点执行今天剩余次数。

### 4.5 任务管理（查询 / 修改 / 启停 / 跳过 / 取消）

- 操作步骤：
  1. **查询**：任务中心/工作台/对话「这周五有哪些任务」；取消前 Agent 会先列出准确任务。
  2. **修改**：「把周五的关灯改到 19 点」→ 变更卡核对「当前安排 → 提案安排」→「确认修改」。
  3. **启停**：详情「暂停重复安排」（只影响以后）/「继续执行」（重新检查设备权限）。
  4. **跳过**：「跳过本次安排」（其他日期不变）。
  5. **取消**：详情/变更卡「取消任务/取消本次/取消全部」→ 二次确认。
- 结果与判读：「取消这个周期全部尚未执行的安排；已执行或已发送的动作保持原样」「只取消这一次，后续周期照常执行」。
- 注意事项：管理他人任务需要创建者账号且范围覆盖全部设备；删除重复安排保留已生成任务与历史报告。

### 4.6 任务报告与引用追问

- 操作步骤：任务详情「查看最近一次报告」/ 通知打开报告 →「引用本报告/引用任务并询问」→ 对话追问。
- 结果与判读：报告为生成时保存的事实（含计量依据/检查时间/覆盖范围），不重新执行；PDF/表格可「下载 PDF」「导出表格」。
- 【截图：报告预览页】

## 5 公司 Agent 业务能力

> 公司端覆盖微脑目录下环境/计量/安全/空调/照明/门禁/视频设备；
> 观察类设备（环境/计量/安全/视频）只读，可控设备（照明/空调）走确认草案。

### 5.1 设备查询与控制

- 场景示例：「公司照明全开」「关掉三楼的空调」「这层除了会议室都关灯」。
- 操作步骤：同 4.2/4.3；范围草案显示「拟执行 N 台 · 保留 N 台 · 无需调整/需要调整/暂未读到状态」。
- 结果与判读：大范围草案按位置分组概览，可查看全部、勾选排除、搜索设备。
- 注意事项：「公司/全部/授权范围」是来源范围，位置为空仍可用；子区域限定不会扩大成整层；具体地点/简称/错字按授权目录解析后在卡片列明。

### 5.2 能耗业务

- 场景示例：「统计一下最近能耗情况」「本月和上月比怎么样」「上周哪天用电最多」「导出一份 10 月用电报告」「帮我看看最近夜间哪个场所耗电异常」。
- 能力明细：
  1. **区间统计**：任意起止窗口用电合计（度）+ 逐表明细 + 覆盖说明；
  2. **用电对比**：同比（去年同期）/环比/任意两期；跨层级或台数不同按单台平均；两期有效时长不等按日均（度/日）；
  3. **计量点历史**：单表 `[from,to)` 原始累计示数与采样时刻（非期间用电）；
  4. **报告附件**：生成用电报告（下载 PDF / 导出表格），含计量依据与覆盖说明；
  5. **夜间用电**：20:00→次日 08:00 窗口统计与排名（夜间负荷 = 窗口用电 ÷ 12 小时，度/时，与夜间用电量不同口径）。
- 结果与判读：
  - 缺测/回退/停报/覆盖不足显示「不可计算」「暂无可合计的区间用电」「部分电表采样不全」，不补零；
  - 「所选期间包含客户模拟补数，不作为真实运行或节能证据」；
  - 计量依据行显示有效/预计覆盖与口径（末端表可相加、单位为度）。
- 【截图：用电统计卡 / 用电对比卡 / 报告附件卡】

### 5.3 环境业务

- 场景示例：「现在机房温度多少」「昨天下午湿度趋势怎么样」。
- 能力：实时读数（带来源标注）+ 任意窗口历史趋势 + 窗口引用提问。
- 结果与判读：站点采样是站点级数据，不自动归属房间；单位未确认的指标不判断是否达标。
- 【截图：环境趋势卡】

### 5.4 安全业务

- 场景示例：「最近有哪些消防告警」「这条告警附近的监控给我看看」「帮我整理一下最近一周的告警并产出报告」。
- 能力：台账查询（类别/时间窗口，如「近 N 天」「上一自然周」）、事件详情、按当前位置/楼层查找候选监控（记录前后各 15 分钟录像窗）。
- 结果与判读：多个候选未选定时 Agent 先简短询问想看哪个位置，不罗列全部、不自行选择；候选不证明覆盖，回放不证明当前已恢复。
- 注意事项：Agent 不处置告警、不自动联动；回答会给出简短具体的后续建议（核实什么/交给谁/如何反馈）。
- 【截图：台账块 / 候选监控卡】

### 5.5 视频观察

- 能力：授权目录内摄像头的实时画面与录像回放（单次最长三天）。
- 操作步骤：「看看大堂摄像头」→ 直播卡「看直播」；「回放昨天下午两点东侧的录像」→ 回放卡「查看这段录像」→ 填写/核对录像期间 → 取流播放。
- 结果与判读：视频块三态——在线/离线/在线状态未知；取流失败 ≠ 播放失败 ≠ 设备离线，分开提示。
- 注意事项：客户 H5 播放页未配置时按钮置灰「播放页接入中」。

### 5.6 定时与周期任务（公司侧）

- 同 4.4/4.5，另含公司特有形态：
  - **空调条件任务**：「每 30 分钟检查机房空调，超过 28℃ 调到 26℃」——服务端按 15/30/60 分钟展开检查点，条件与动作有白名单；卡片显示「共 N 次检查」与窗口。
  - **空调巡检**：逐台检查 + 生成报告；只下发、不调温的行写「已下发调到 X℃ · 平台回读 Y℃ · 检查前 Z℃」。
  - **节能估算**：只有至少一台实际调温后才有节能块——「预计节电约 N 度 · 折合电费约 ¥X（估算值）」+ 依据行（调前平均温度、经验节电率、估算窗口、未参与台数）；全程关机/只读/未调温显示「暂无法可靠估算」及原因；估算值明确标注非实测。
  - **安全台账汇总**：「汇总上周安全告警」等只读周期任务（上一自然周，周一至周日）。
- 【截图：空调条件任务卡 / 巡检报告】

### 5.7 公司夜间收口计划

- 场景示例：「安排每天下班后关掉公司照明和空调」。
- 操作步骤：提出收口目标 → 收口计划卡 → 确认登记 → 对话中可继续补充收口项。
- 结果与判读：每天按授权目录重核、形成待确认提案；未确认不执行。

### 5.8 外部告警深链（客户消息卡片）

- 功能说明：客户告警平台通过微信「设备订阅消息」卡片跳到小程序，直达公司 Agent 浮层。

### 6.1 状态与口径词表

**任务状态**：待确认 / 已创建 / 进行中（待执行·执行中）/ 已结束 / 已取消 / 已放弃 / 已过期 / 已暂停 / 已开启 / 已删除。
**执行结果**：已完成 / 已下发 / 部分完成 / 失败 / 错过 / 中断 / 已检查 / 无需调整 / 无需操作。
**设备状态**：开关类「已开启/已关闭/状态未知」；视频「在线/离线/在线状态未知」；读数类「数值 + 单位 + 读数时间」。
**口径词**：已下发（指令受理无回传）/ 平台回读（实测返回）/ 平台影子值（协议回显，非实测）/ 快照（约 60 秒缓存）/ 缺测（采样缺失，不补零）。

### 6.2 常见问题

- **为什么看不到某台设备？**——超出当前身份授权范围，或身份/园区切换后目录已重载。
- **「已下发」但设备没变？**——平台未回传实测；以现场与平台回读为准。
- **能耗显示「—」/「不可计算」？**——采样缺失、停报或覆盖不足，不是零用电。
- **「暂不可用」与「无未读/暂无任务」的区别？**——前者是读取失败，后者是确实没有数据。
- **核验过期？**——草案超过有效窗口，需「重新核验」后再确认。

### 6.3 数据时效说明

- 概览/目录/能耗/任务列表为短时快照：60 秒内同身份复用并合并在途请求；手动刷新强制重读；确认/取消等写操作立即失效。
- 任务日历：历史月永久复用、当月与未来月 60 秒；实时只刷新今天（执行中 5 秒、其他 30 秒）。
- 工作台可见时 30 秒常态刷新、任务执行中 5 秒；页面隐藏后停止。
- 能耗后台冷读可能显示「数据准备中，后台正在读取历史电表数据」，允许重试。
