## 1 概述

### 1.1 系统简介
- 物联 Agent 是小程序内的物联网智能体子系统，由三部分构成：
  - **物联助手仪表盘**（公司 Agent 入口与总览，路径 `pages/agent/dashboard`）
  - **办公室 Agent**（员工端对话与工作台，路径 `pages/agent/index`）
  - **区域工作台**（办公室端的任务时间轴与设备浏览，路径 `pages/agent/region`）
- 公司 Agent 以仪表盘右下角浮层承载；办公室 Agent 为独立页面。
- 【待补：产品定位一段话，面向读者的能力总览】
- 【截图：仪表盘首屏】

### 1.2 运行环境与前置条件
- 微信小程序（客户正式版 / 开发版）；微信账号登录并完成组织确权。
- Agent 的设备可见范围 = 当前用户的**授权设备范围**；不同身份看到的设备与可办业务不同。
- 【待补：版本号、AppID、网络要求】

### 1.3 术语约定
| 术语 | 含义 |
| --- | --- |
| 草案 / 操作卡 | 设备控制执行前的待确认卡片；只有确认后才会下发设备指令 |
| 提案 / 任务卡 | 定时或周期任务的待确认卡片；点击「创建任务」才登记 |
| 任务 Task | 一次性或到点执行的具体执行单 |
| 周期计划 Plan | 按日/周重复的计划，到点生成实际 Task |
| 台账 | 安全/告警事件记录列表 |
| 回读 | 平台返回的设备状态数据；「已下发」指指令已受理，「平台回读」指有实测数据 |
| 检查点 | 周期条件任务中由服务端展开的执行时刻（15/30/60 分钟间隔） |

## 2 基础能力指引（通用操作）

### 2.1 登录与身份
- 功能说明：进入小程序后使用微信登录；Agent 依赖登录态与园区上下文。
- 入口：服务首页 → 登录页 →（我的 → 组织确权）。
- 操作步骤：【待补：登录 → 确权 → 进入首页】
- 结果与判读：【待补：未登录/未确权的表现】
- 注意事项：切换身份或园区后，Agent 会话、目录与未读状态全部按新身份重新加载；旧身份内容不再保留。

### 2.2 入口导航
- 功能说明：物联 Agent 的唯一固定入口是服务首页「物联助手」单行菜单（玉漆图标）。
- 入口：`pages/index/index` → 「物联助手」→ 仪表盘 `pages/agent/dashboard`。
- 操作步骤：服务首页点击「物联助手」→ 进入仪表盘；仪表盘标题栏「办公室」→ 办公室 Agent 页。
- 结果与判读：【截图：首页菜单 / 仪表盘标题栏】
- 注意事项：办公室 Agent 没有独立菜单入口，只从仪表盘标题栏进入；页面内的返回统一走导航栏「‹ 服务首页/总览」。

### 2.3 对话基础操作
- 功能说明：双端 Agent 共用同一会话界面（办公室为整页，公司为浮层）。
- 操作步骤：
  1. 输入文字 → 点发送；公司端空会话欢迎区有推荐问法 chips，点击只预填、需再点发送。
  2. 语音输入：【待补：语音输入入口与使用】
  3. 长按/点按自己最近一条消息：可**编辑重发**或**重试**（失败轮恢复入口）。
  4. 清空会话：头部菜单清空历史（无会话时按钮置灰）。
- 结果与判读：答复实时流式展示；「检索思路」为过程记录，可展开；卡片可先于终稿落位。
- 注意事项：刷新或返回再进，会话记录保留；运行中收起/切页不中止任务（公司浮层 orb 上亮运行环）。

### 2.4 引用机制
- 功能说明：把一条业务记录（安全事件、环境窗口、任务、告警卡片）带进对话，让 Agent 围绕它回答。
- 入口：台账详情「引用」、环境历史「向公司 Agent 询问此期间」、任务详情/列表「引用」、客户告警卡片跳转。
- 操作步骤：在详情页点引用 → 输入区出现引用条 → 补充问题发送；引用条可移除；已有草稿只询问是否替换。
- 结果与判读：发送时服务端按当前授权重新核验记录；引用本身不代表授权。
- 注意事项：跳转变回 dashboard 时引用经深链暂存送达；不会自动发送。【截图：引用条】

### 2.5 确认机制
- 功能说明：任何设备控制、任务创建、任务取消、修改都必须先出卡片、人工确认。
- 操作步骤：对话中提出请求 → Agent 生成操作卡/任务卡 → 点「确认执行/创建任务」→ 或「放弃」。
- 结果与判读：确认后卡片转为执行态；放弃仅退役卡片，不执行任何动作；新消息会使旧卡片失效。
- 注意事项：范围类草案（如整层照明）显示设备数量与排除项，确认前可核对；重复确认只会回放结果，不会重复执行。

### 2.6 结果与失败判读
- 功能说明：任务/控制结果统一口径——
  - **已下发**：指令已受理但平台未回传实测（不写「已完成」）；
  - **已完成 / 平台回读**：有回传数据支撑；
  - **失败/部分完成/错过/中断**：标异常，可点「查看原因」读完整可复制的原始原因。
- 注意事项：「已下发」不算异常；不要把指令目标当成设备实际状态（如调温 26℃ 是目标，回读值才是实测）。

### 2.7 通知与收件箱
- 功能说明：任务结束消息、执行摘要进入站内收件箱；Agent 头部显示未读数。
- 操作步骤：点头部收件箱图标 → 列表 → 点单条打开同源报告/任务 → 成功读取后标记已读。
- 结果与判读：周期计划/空调巡检等报告附带通知；未读数失败显示「暂不可用」而不是「无未读」。
- 【截图：收件箱】

### 2.8 页面层级与返回
- 功能说明：所有详情（任务、设备、台账、报告）以底部 Sheet 打开，支持多层导航。
- 操作步骤：左侧「‹」退局部一层（如详情 → 列表）；右侧「✕」关闭整层；微信原生返回逐层退。
- 注意事项：抽屉内是单层三级栈（列表 → 设备时间轴 → 任务详情），不是叠多个弹窗。

## 3 页面与组件说明

### 3.1 物联助手仪表盘（pages/agent/dashboard）

#### 3.1.1 页面骨架
- 顶部：导航「物联助手」+「办公室」入口按钮。
- 问候行：日期 + 姓名（取个人信息实名，回退昵称/脱敏手机号）。
- 右侧：精简/详细模式切换（默认精简，偏好记忆）+ 刷新按钮。
- 【截图：两种模式对照】

#### 3.1.2 精简模式
- 状态灯：汇总环境/用电/安全的注意项与分区错误（正常/注意/异常 + 一句话结论）。
- 2×2 状态块 + 任务/设备/通知块：
  - **环境**：最新读数摘要 → 点进环境历史趋势。
  - **用电**：仅在上一个完整计量日存在时给差值，缺数显示「—」→ 点进能耗统计。
  - **安全**：最近一条台账是否在近 30 天内给「有记录」（不代表实时报警）→ 点进安全台账。
  - **接下来（任务）**：62 天任务窗的小议程 → 点进任务中心。
  - **设备**：打开全量设备目录抽屉（只读）。
  - **通知**：打开通知中心，带未读数。
- 底部「直接问助手」→ 展开公司 Agent 浮层。
- 注意事项：任务块与通知块各自独立加载，一侧失败不影响另一侧。

#### 3.1.3 详细模式
- 设备分类计数行：环境/能耗/安全/空调/照明/门禁/视频各类数量，点某类开该类的只读设备抽屉。
- 环境传感器块：实时读数（温度/湿度/PM/CO₂ 等，随传感器配置），「趋势 ›」进环境历史。
- 能耗统计块：横滑日柱条带（斜排日期、拉满松手开详情）+ 月度对比（环比/同比，点整块展开逐表明细）。
- 安全台账块：按类型 chips 筛选的最近记录行，「全部 N 条 ›」进台账列表。
- 自动化安排块：即将到来的任务/周期计划摘要，点进任务中心。
- 底部：双 Agent 入口（公司浮层 / 办公室页）。
- 注意事项：模式切换不重新拉取数据；各块失败独立显示重试，不拖垮整页。

### 3.2 公司 Agent 浮层（CompanyAgentFloat）
- 功能说明：常驻右下角 orb，点开后是约至导航栏下沿的对话面板；orb 兼任收起把手。
- 操作步骤：点 orb 展开 → 对话同 2.3；点遮罩或 orb 收起；空会话欢迎区显示 4 条推荐问法。
- 结果与判读：收起时运行中 orb 亮运行环、有新消息亮未读角标；草稿保留。
- 【截图：orb 收起态 / 面板展开态】

### 3.3 办公室 Agent 页（pages/agent/index）
- 功能说明：员工端整页对话 + 头部入口。
- 组件：AgentHeader（连接状态、清空会话、返回）+ 区域 chip + 三个入口：工作台、任务（我的任务）、收件箱（未读数角标）。
- 结果与判读：头部状态随会话连接/运行变化；断线有错误提示。
- 【截图：头部区】

### 3.4 会话主体（AgentConversation 共用）
- 消息流按事件序渲染：用户气泡、正文答复、检索思路（工具调用过程折叠）、观察卡、操作卡、任务卡、报告卡、错误卡。
- 输入区：文本框、引用条、发送；编辑旧消息时保留原轮引用。
- 观察卡只读事实呈现：视频「在线/离线/未知」+「查看画面」、环境读数带来源、能耗最新已知读数、安全台账摘要。
- 注意事项：「查看画面」现取短时效流地址后在 H5 播放器打开；取流失败 ≠ 播放失败 ≠ 设备离线，三态分开提示。

### 3.5 区域工作台（pages/agent/region，仅办公室端）
- 功能说明：按区域看任务时间轴与设备。
- 组件与操作：
  1. 顶部：日期标题（今天/X 月 X 日）+ 记录数；RegionTimeline 纵向时间轴，滚动跨天自动扩展。
  2. 左上浮动日历 chip：点开月视图选日；点日期定位到该日第一张任务卡。
  3. 任务细卡：任务名、设备头像、创建者标记（本人显示「我」）；状态点：黄铜=部分完成、红叉=失败/错过/中断、「已取消」、强调=执行中。
  4. 底部停靠栏：「设备」（数量角标）+「＋ 新建任务」（回到对话并把当前区域写进预填开头）。
  5. 设备抽屉：设备列表（类型/位置/状态互斥分组 + 搜索）→ 点设备进设备时间轴 → 点任务进任务详情；三级导航栈。
  6. 任务详情：阶段、设备执行组（多设备可展开）、结果、报告、「取消任务」（带二次确认）。
- 结果与判读：到点执行后时间轴静默刷新；区域 chip 黄铜点表示有未查看的异常任务。

- 【截图：时间轴 / 日历浮层 / 设备抽屉三级】

### 3.6 任务中心（TaskListSheet 双端共用）
- 功能说明：任务、周期安排、通知三个视图的统一入口。
- 视图：
  - **全部任务**：按日分组的任务列表（与首页议程同一数据窗）。
  - **日历**：月视图带任务点（橙点=有异常），点日看当日任务。
  - **周期安排**：计划列表 + 启停开关（停用只影响未来发生，需确认后重核目录；重新启用亦需确认）。
  - **通知中心**：结束消息/报告通知，点开同源报告后自动已读。
- 操作：手动下拉刷新；任务卡进详情；详情内取消（403/409 保留并刷新）。
- 注意事项：周期启停即时生效且只作废计划快照；通知已读即时反馈。
- 【截图：三视图】

### 3.7 观察类面板（DeviceSheet 承载）
- **安全台账**：分类/日期分页列表 → 单条详情（快照+读取时间）→「引用」带进公司 Agent；「按当前位置查找监控」找候选摄像头。
- **环境历史**：趋势折线（缺测断段不连线）+ 时间窗 →「向公司 Agent 询问此期间」。
- **计量历史**：单表 `[from,to)` 区间原始累计示数 →「向公司 Agent 询问此期间」预填。
- **能耗统计面板**：日柱/逐日明细/对比，选日记忆、跳远日期、「现在」回今天。
- **设备目录抽屉**：全量或单类设备只读列表。
- **视频播放**：直播/回放表单（摄像头 + 时间段，≤3 天）→ H5 播放器页。
- 注意事项：这些面板对双端均只读；公司端观察数据不进入办公室端。

## 4 办公室 Agent 业务能力

### 4.1 设备查询与状态
- 场景示例：「三楼东侧照明现在什么状态」「会议室空调开没开」。
- 操作步骤：对话提问 → Agent 检索授权目录 → 返回设备列表/状态；点设备行进详情。
- 结果与判读：状态读数为平台当前回读；开关类显示开/关，观察类显示在线/读数。
- 注意事项：只能说授权范围内的设备；范围外设备会回复找不到（不透露存在）。

### 4.2 设备控制（照明 / 空调 / 门禁等）
- 场景示例：「关掉本层照明」「把会议室空调开到 24 度」。
- 操作步骤：提问 → 确认设备范围与参数 → 操作卡「确认执行」→ 看下发结果。
- 结果与判读：按 2.6 判读；范围操作可排除部分设备。
- 注意事项：参数可长按调整；未确认的卡随新消息失效。

### 4.3 定时与周期任务
- 场景示例：「明天 18:00 关掉本区域照明」「每个工作日 17:30 检查办公室设备」「每天上午 9 点给我一份环境简报」。
- 操作步骤：描述时间与动作 → 任务卡核对（时间/设备/动作）→「创建任务」。
- 结果与判读：到点执行产生结果与报告，进收件箱；周期任务在「周期安排」集中管理。
- 注意事项：区间任务可带多个自由检查点；只读任务（巡检/简报）不产生控制。

### 4.4 任务管理与取消
- 操作步骤：任务中心/工作台打开任务 → 详情 →「取消任务」或取消提案卡；周期任务可「取消本次/取消全部」。
- 结果与判读：取消后时间轴隐藏该任务，设备实际操作记录保留；未下发的设备不显示为故障。

### 4.5 任务报告与引用追问
- 操作步骤：任务详情/通知打开报告 → 点「引用」→ 对同一任务追问。
- 结果与判读：报告为持久化事实，不重新执行；引用追问由服务端按最新授权复核。
- 【截图：报告页】

## 5 公司 Agent 业务能力

### 5.1 公司设备查询与控制
- 场景示例：「公司照明全开」类大范围操作（含排除）、空调开关与调温。
- 操作步骤：同 4.1/4.2；范围草案显示路数/台数与排除明细。
- 注意事项：公司端设备目录与办公室端完全独立；无办公室的区域/工作台入口。

### 5.2 能耗业务
- 场景示例：「上周哪天用电最多」「本月和上月比怎么样」「导出一份 10 月用电报告」。
- 能力：
  1. **区间统计**：任意起止窗口的用电合计与逐表明细（单位：度）。
  2. **对比**：同比/环比/任意两期；跨层级或台数不同按单台平均。
  3. **计量点历史**：单表原始累计示数与采样时刻。
  4. **报告附件**：生成 PDF/表格附件供下载。
  5. **夜间用电**：20:00→次日 08:00 夜间统计与排名。
- 结果与判读：缺测/停报显示「不可计算」或缺数说明，不补零；估算口径常驻标注。
- 【截图：能耗对比卡 / 报告卡】

### 5.3 环境业务
- 场景示例：「现在机房温度多少」「昨天下午湿度趋势怎么样」。
- 能力：实时读数 + 任意窗口历史趋势 +「询问此期间」窗口引用。
- 注意事项：趋势缺测段断开不连；读数带来源标注。

### 5.4 安全业务
- 场景示例：「最近有哪些消防告警」「这条告警旁边的监控给我看看」。
- 能力：台账查询（分类/时间）、事件详情、按当前位置/楼层查找候选监控并回放。
- 结果与判读：多候选时 Agent 先询问看哪个位置，不自行选择；不处置告警。
- 【截图：台账 / 事件详情 / 录像卡】

### 5.5 视频观察
- 能力：摄像头实时画面与录像回放（授权目录内）；回放最多取三天窗口。
- 操作步骤：「看看大堂摄像头」「回放昨天 14 点东侧的录像」→ 观看卡 → 点击取流播放。
- 注意事项：地址未配置时按钮置灰「播放页接入中」。

### 5.6 定时与周期任务（公司侧）
- 同 4.3/4.4，另含公司特有：
  - **空调条件任务**：如「每 30 分钟检查机房空调，超过 28℃ 调到 26℃」——服务端展开 15/30/60 分钟检查点，条件/动作有白名单。
  - **空调巡检**：生成逐台检查报告与节能估算（实际调温后才估算，全程关机/只读无节能行）。
- 结果与判读：巡检行写「已下发调到 X℃ · 平台回读 Y℃」，目标值不等于实测值。

### 5.7 公司夜间收口计划
- 场景示例：「安排每天下班后关掉公司照明和空调」。
- 操作步骤：提出收口目标 → Agent 生成夜间收口计划卡 → 确认登记 → 可在对话中补充收口项。
- 结果与判读：到点形成待确认提案，未确认不执行；每天按授权目录重核。

### 5.8 外部告警深链（客户消息卡片）
- 功能说明：客户告警平台通过微信订阅消息卡片跳到小程序，直达公司 Agent。
- 操作步骤：点消息卡片 → 打开仪表盘并展开公司 Agent → 显示「客户告警引用」chip 并预填问题 → 手动发送。
- 结果与判读：引用按当前授权核验；不自动发送、不自动处置。
