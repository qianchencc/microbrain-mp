# EgoLite 当前账号办公室设备注册基线

> **范围修订（2026-09-14）：** 本记录只保留为管理注册和 provider 映射诊断证据。Agent 测试环境与用户设备范围必须以客户 Office/工作区同级用户设备接口族聚合结果为准；“我的办公室”只是其中一个不完整来源；“智慧”类入口属于云起面板，不参与 Agent 范围发现。

当前“我的办公室”真实契约与测试账号结果见 `docs/research/2026-09-14-my-office-device-scope-contract.md`。该账号通过该来源观察到 1 个办公室中的 7 台设备；这不是完整聚合范围，也不是本记录中的 137 条管理注册记录。

日期：2026-09-14

## 目的

本记录用于重建本地测试环境和设计 Runtime 的统一设备注册层。数据来自当前 EgoLite 已登录的客户账号，不保存 token、cookie、client secret、设备 ID 或其他凭据。

## 账号与入口

当前登录账号是客户门户中的系统管理员账号。门户可见的物联应用包括“我的办公室”“智慧空调”“智慧照明”“智慧门禁”“视频监控”等。

需要区分两种语义：

1. **办公室管理注册目录**：管理端“我的办公室 → 设备管理”使用 `/micro-api/api/office/device/page`，表达该办公室系统中的注册设备，适合做注册基线和管理诊断。
2. **当前用户设备范围**：Office Scope Family 的各同级来源按当前用户办公室/区域上下文返回设备，Runtime 聚合后形成 Agent 的授权设备范围；“我的办公室”只是其中一个来源。

二者不能因为同一个账号或同一个租户而合并。超级管理员能看到管理注册目录，不代表普通用户可以操作其中全部设备。

## 当前真实返回

管理端设备分页请求需要同时携带授权头和 `tenantCode`。当前账号返回 137 条办公室注册记录，所有记录的网络状态均为在线。

| 注册类型 | 数量 | 观察到的能力/子类 |
| --- | ---: | --- |
| `SECURITY_PROTECTION` | 31 | 监控 `VIEW`、门禁远程开门、授权码开门、静态密码修改等；其中 6 条为视频、22 条为门禁，另有 3 条安全设备待进一步分类 |
| `AIR_CONDITION` | 28 | 主要是云起中央空调注册记录；管理注册记录本身未直接带完整空调动作 |
| `LIGHTING` | 75 | 开关照明，绝大多数同时有打开/关闭动作 |
| `ENVIRONMENT` | 3 | 当前名称和动作表现为三菱遗留空调控制器，暂不进入默认 Agent 控制能力 |

管理注册记录中还观察到：照明存在少量动作名称与动作类型不一致的记录；门禁存在“远程开门”和“门禁设备控制”两种动作命名；这些字段不能直接当成统一 Agent 工具，必须经过能力规范化和白名单校验。

此前对四类 `myAreaList` 的局部探测均返回业务码 204，但这些请求不属于“我的办公室”页面的完整范围契约，因此不能用于判断办公室分配为空。按页面真实契约复核后，当前账号实际拥有 1 个办公室和 7 台设备。管理端 137 条记录仍不能回填用户范围，也不能退回云起通用目录扩大范围。

## 对测试环境的结论

本地测试环境应同时模拟两种数据集，但分开命名和使用：

- `officeRegistry`：模拟办公室管理端注册目录，用于注册层、类型映射、能力诊断和 fixture 生成；不直接进入模型上下文。
- `officeUserScope`：模拟某个用户通过 Office Scope Family 实际得到的可操作设备；这是 Agent 的唯一发现上游。“我的办公室” fixture 只代表其中一个来源。

测试账号至少需要两个：同一租户下的管理员注册视图，以及两个设备分配不同的普通用户视图。`officeUserScope` 为空时，Agent 应报告当前用户没有该类可用设备，不能改用 `officeRegistry` 或云起目录补齐。

## 后续工程边界

1. Agent 直接使用客户小程序当前登录用户的 token 调用已声明的用户设备接口；不复制用户模板、区域操作人员或设备分配权限。
2. 管理注册记录中的 `id`、`hubDeviceId`、`elementId` 等只在适配器需要调用具体接口时使用；它们不改变用户范围，也不要求 Agent 理解上游注册流程。
3. 客户接口已有响应体，Runtime 后续只需按已确认契约接入状态读取/回读；控制受理与物理状态仍按不同字段表达。
4. 更多设备类型暂不接入；管理、云起、感知和能源目录继续作为非范围数据，不回填 Agent 设备列表。
