# B6 时间轴设计

状态：可评审原型，尚未获最终视觉确认，非生产实现。入口：`../../pages/agent/prototypes/proto-region-panel.html?variant=b6`。唯一设计稿：`b5-node-time-concept-v2.png`。`b4-frozen-reference.png` 仅用于检查 B4 未被改动，不是第二份设计稿。本轮仅定义时间轴、区间、节点和时刻；任务卡内容及自动化执行不在该组件契约内。

设计稿的 15:30 至 15:42 视觉间距约 57px，和 14:00 至 15:30 的约 156px 不成真实时间比例。原型必须坚持固定 `34px/h`：因此这两个节点在 B6 中会比设计稿更近，文字相撞时只隐藏“现在 / 时刻”，绝不拉伸时间或推开终点。B4 的 `railX(y)` 曲线已冻结，B6 复用它；参考图的局部外鼓不能靠另画一条左边界伪造，只能在同源右侧宽度函数上打磨。

## 固定输入

- B4 的主曲线函数 `railX(y)` 与每小时 `34px` 的比例不改。区间左边界取这条主曲线，右边界沿其右法线展开；灰色主轴在区间内被实心材质覆盖。
- B6 复用 B4 的单侧收放轮廓，但只生成一次完整路径。深浅材质复用这一片轮廓，按当前时间裁切，不再各自生成独立多边形，也不另画区间内的前缘线。
- 起点是玉绿实心圆，终点是白心玉绿圆环，当前时间是黄铜实心圆。三者都位于真实时间对应的曲线上；当前时间经过端点时自然叠绘，不移动端点、不换形状、不局部拉伸时间。
- 区间内的已流逝部分为深玉绿，未来部分为浅玉绿，分界与唯一的当前时间同高。没有空心槽、第二条进度线或循环流光。

## 组件设计语言

| 构件 | 视觉角色 | 坐标及状态规则 |
| --- | --- | --- |
| 主轴 | 低对比度的连续鼠尾草绿曲线，已流逝段略深 | 唯一 `railX(y)`；`y` 由日期和时刻按恒定比例确定，跨日不断开。 |
| 区间实体 | 沿主轴右侧展开的玉绿缎带，两端窄、中段饱满 | 左缘即主轴；右缘沿局部法线偏移。未来浅、已过深；截面只由当前时间决定。 |
| 普通事件点 | 灰绿圆点，白色隔离边；未来为空心 | 事件精确时刻在主轴上。形状表达时间锚点，不承担任务完成状态。 |
| 区间端点 | 起点实心玉绿、终点白心玉绿环，均有白色隔离边 | 与区间先后叠绘并覆盖接缝；当前节点接近时端点不偏移。 |
| 当前时间 | 单个黄铜实心圆及向右的短虚线 | 坐标恒等于真实当前时间。经过区间时同时决定深浅分界，节点位于所有区间及端点上层。 |
| 辅助刻痕 | 浅灰绿短圆角实体条，外侧细白间隔 | 每三小时候选一次；落在区间内或接近事件、端点、当前节点时，图形和文字一同省略。 |
| 时间文字 | 左栏右对齐；精确事件深于辅助刻度 | 固定事件时刻优先，普通刻度次之；移动的“现在 / HH:mm”碰撞时整组隐藏。 |
| 日期分界 | 与午夜同高的轻量分隔文字 | `24:00` 和次日 `00:00` 只渲染一个 `00:00`，日期不另占时间高度。 |

渲染顺序为主轴、刻痕与连接线、区间浅色轮廓、同轮廓的已流逝材质、普通事件点、区间端点、当前时间节点、文字与任务卡。它决定白边能盖住缎带接缝，也决定黄铜节点经过端点时只发生自然叠绘。页面卡片是时间轴的内容投影，不反过来决定节点坐标。

色彩以语义区分：鼠尾草绿是时间结构，玉绿是区间范围与已流逝部分，黄铜只指示当前时间。计划、执行中、完成、部分完成等业务状态写在内容中，不借用黄铜节点或改造区间端点。曲线和进度没有循环动画；演示时钟变化直接更新位置与材质，`prefers-reduced-motion` 下不依赖动效传达状态。

## 时间与刻度

- 普通三小时刻度统一画成嵌在曲线上的浅灰绿**短圆角实体条**，留一圈细微白色间隔；不是穿过曲线的发丝线，也不是圆形事件节点。
- 若普通刻度落在任一区间内，或距离普通事件节点、区间端点、当前时间节点过近，则**刻度图形与刻度时间文字一起省略**。精确事件时刻及其节点保留。
- `24:00` 与次日 `00:00` 是同一瞬间。B6 跨日不插入无时间含义的高度，只显示一次 `00:00`；日期分隔文字位于该时刻右侧，曲线连续。
- 精确事件时刻优先、刻度时刻次之。“现在 / HH:mm”是可让位的两行文字：只要与已有时刻文字相撞，就整组隐藏；黄铜当前时间节点和进度位置始终显示。固定时刻文字不因当前时间移动而跳动。

## 状态与边界

- 区间前、区间中、区间后都保持相同的区间轮廓和节点角色，只改变深浅材质及当前时间位置。
- 多区间重叠的演示仍以 `&case=overlap` 查看：主曲线只有一条，外侧区间独立成层，当前时间前缘仍唯一。这是参考图以外、尚未确认的探索状态，不作为可复用组件规范。
- 任务是否计划、完成、部分完成或取消由内容文字承担，不改变时刻节点形状。

## 核对画面

1. `15:42`：14:00 实心起点、15:30 完整终点圆环、黄铜当前节点均在 B4 曲线上；区间整体深玉绿。由于文字相近，“现在 / 15:42”可隐藏，但黄铜节点不能隐藏。
2. `14:45`：当前节点与区间深浅截面同高，落在区间内的普通刻度不出现。
3. `08:45`：邻近 09:00 的普通刻度图形和文字均不出现；08:45 空心事件圆环完整。
4. 跨 9/24 至 9/25：只有一个 `00:00`，日期分隔与之关联，无 `24:00` 或空白时间段。
5. `variant=b4`：原有曲线、时间布局和区间节点行为仍可独立对照。

## 本轮验证和未达成项

- 浏览器已核对 `15:42`、`14:45`、次日 `08:45`、跨日 `00:00` 与双区间探索态。默认画面中终点和当前节点都落在真实曲线上；`15:42` 的当前时间文字隐藏但节点保留；`14:45` 的深浅截面与当前节点同高；`08:45` 邻近的 `09:00` 刻痕及文字一起消失；跨日只有一个 `00:00`，没有 `24:00`。
- 对照裁切后撤销了“中段恒宽”的试验：它让外缘变成斜杠。保留 B4 原有的渐收轮廓，B6 只重写深浅进度为同一形体的裁切。设计稿是视觉草稿，无法作为逐像素数学曲线；核对重点是连续单侧缎带、真实时间位置和节点叠绘。
