# B5 时间轴设计

状态：B5 探索记录，近时刻端点避让与细线刻度已被 [B6 设计](./b6-timeline-design.md) 废弃。入口：`pages/agent/proto-region-panel.html?variant=b5`，仅供历史对照。

## 设计依据

- B4 的连续主曲线及 `34px/h` 时间映射是固定输入，B5 不改曲线函数、振幅、波长和单区间轮廓。
- 区间沿主曲线右侧的实心形体保持 B4 形状；B5 只补齐节点与多区间同时出现时的清晰表达。
- 当前时间是唯一的黄铜色进度前缘。区间内，深玉绿已流逝部分与浅玉绿未来部分在该时刻相接；区间外，前缘仍停在同一条曲线上。
- 参考图只展示单个、已流逝的区间。未来、区间内、近时刻碰撞和重叠区间是依据同一视觉语言补出的原型规则，不能冒充图片中已有的设计。

## 节点语言

| 角色 | 不变的形状 | 可变的时间状态 |
| --- | --- | --- |
| 普通时刻 | 有清楚色芯与白色隔离边的小圆盘 | 已过为灰绿实心；未来为同尺度灰绿空心。任务结果不改变节点。 |
| 区间起点 | 比普通点更醒目的玉绿实心圆 | 未来时整体材质减淡，仍保留实心圆身份。 |
| 区间终点 | 白心、玉绿描边的完整圆环 | 未来时描边减淡；即使已过，也不填芯或变成横杠。 |
| 当前时间 | 白色隔离边的黄铜实心圆 | 始终只有一个；它不是“执行中”标记。 |
| 辅助刻度 | 垂直于曲线的细短划线 | 只提供读数，不画成事件圆点。 |

节点优先表达时间角色。计划、部分完成、取消、执行中等业务状态由内容文字承担，不借用黄铜当前时间或终点圆环的形状。

## 冲突绘制

1. **近时刻碰撞**：所有节点仍取真实时间纵坐标。若区间端点圆环与当前时间的白边将相撞，当前时间留在主曲线上，端点圆环沿曲线右法线轻避让，并用短细线接回准确锚点；不改变圆环、不挪动时间坐标、不缩小文字。完全同一时刻也遵循此规则。
2. **重叠区间**：主曲线仍只有一条。按开始时间为区间分配稳定的右侧层位；第一层紧贴主曲线，第二层在外侧并以底色细缝隔开。每条区间保留自己的实心轮廓和深浅进度；外层端点以短连接回主轴的真实时刻。两个区间共享一个当前时间前缘，不各画一个“现在”。原型只演示两层；更多层先聚合为数量入口，避免堆成不可读的绿色宽带。
3. **业务控制冲突**不是时间重叠。控制目标冲突应在任务创建阶段解决，时间轴不额外涂红或显示“冲突”状态。

## 排版与动效

- 精确时刻左侧右对齐，使用等宽数字；起点和终点各有独立时间。普通三小时刻度更轻，靠近精确时刻时省略刻度文字。
- “现在”与当前数字分两行。文字避让只影响标签，引线回指真实锚点；节点不因文字排版而偏离其时间。
- 曲线与区间截面跟随演示时钟同步更新；不使用循环流光、跳动或脉冲冒充进度。尊重 `prefers-reduced-motion`。

## 验收画面

- 默认 `15:42`：14:00 起点实心、15:30 终点完整圆环、黄铜当前节点各自清晰；区间整体深玉绿，曲线与 B4 完全相同。
- `13:30`、`14:45`、`15:30`：分别验证区间前、区间内、当前时间恰逢端点。
- `case=overlap`：验证两条区间有独立实体与共同前缘，不合并为一片。
- B4 与 B5 切换后，B4 的曲线、区间和节点仍按原实现绘制。
