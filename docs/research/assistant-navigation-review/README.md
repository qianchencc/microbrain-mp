## 性能条目

[performance.json](performance.json)只保存 wx.getPerformance 返回的 navigation/render 字段；未保存 Authorization、Token、用户消息或请求体。startTime 为原始时间戳，不能当作持续时间。

| 总览 → Office | 1791364634053 | 708 | 47 |

最后两次来自 Company 按钮反复进入/返回。自动化也有选择器失效步骤，失败步骤不算已通过；只保留微信实际生成的 route/render 条目。三个 Company 样本有波动，不能称为完整基准测试。页面共享 index 路由，通过实际操作顺序对应来源，不用路径推断业务。

数据说明开发模拟器切页有等待；不能确定真机、点击到路由开始的响应时间、历史恢复成功时间或唯一根因。restore 的重入保护已核对，不能误报 onLoad/onShow 重复网络请求。
