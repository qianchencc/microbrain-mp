## 验证证据

[verification.json](verification.json)包含 28 个检查场景：

- 15 个页面与抽屉场景：工作台入口、设备→任务、系统逐层返回、日历优先关闭、搜索、显式关闭、整层系统返回、隐藏/恢复、两端往返、新任务正确到 Office。
- 6 个草案参数场景：全部设备、长按、脏值继续/放弃、保存返回搜索、确认失败原位提示。原生确认框已经显示并目视核对；自动化工具的原生确认/取消未生效，最终两种选择由 wx.showModal 夹具回调提供，因此未验证真机确认框按钮。
- 3 个对话恢复场景：编辑态及文本恢复、取消恢复原新消息草稿、阅读位置 `420→420`。
- 4 个入口场景：直达 Company 回总览、无栈总览回服务首页、Company 连点只入一页、直达工作台回 Office。

成功数据及错误响应都来自合成 UI 夹具；参数保存与确认调用也全部拦截，未连接真实设备。隐藏/恢复通过临时进入 Company 再返回验证，不能冒充真实 H5 播放往返。截图中的设备、任务、人员、草稿是测试数据；不是实际执行报告。

测试为 `npm run test:agent` 24/24；HBuilderX 最终微信编译成功；H5 内脚本语法与 `git diff --check` 通过。对源码/CSS 未新增正则契约测试。
