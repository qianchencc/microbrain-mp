# 物联助手导航改进规格

2026-10-07；用户已授权在完整检查基础上实施。基线 `c600229`，检查依据 [导航审计](2026-10-07-page-navigation-audit.md)。仅修改物联助手及其专用视频返回桥，不修改客户其他页面、Runtime 或业务权限。

## 页面与退出规则

- 总览 → 公司 Agent / 办公室 Agent → 区域工作台。公司和办公室仍为创建时固定 source 的独立页面。
- 顶部统一为 44px 返回触区、常驻页面名、独立会话菜单；去除公司页中央的「返回总览」小按钮。返回有历史则回上一页，无历史则 redirect 到所属父页，总览无历史回服务首页。会话菜单只管理会话。
- 区域名始终打开区域选择；办公室页另有明确「工作台」入口。区域错误进入内容区，不挤压导航栏。
- 临时 Sheet 均有明确关闭按钮；内部上一层与关闭整层分开。微信系统返回先消费 Sheet；设备详情/搜索/编辑有下一层时先退一层。保留现有本地遮罩/位移动画，不引入 uni-popup。
- 未保存参数离开时询问是否放弃，保存成功回原搜索或列表；失败留在原处。确认执行不在请求完成前关闭抽屉，错误保留在现场。
- 隐藏页面暂停刷新、保留抽屉、日期、筛选和阅读位置；卸载才释放。跨身份不复用旧目录或草稿。消息编辑内容不覆盖新消息草稿。
- 工作台新建任务明确回办公室对话，不能误回总览/公司；已有输入保留，区域引导不会静默丢失。
- 深链失效/超出展示范围明确提示；不静默失踪。定位按钮明确表示「现在」。视频无返回栈时有显式说明。
- 入口防连续点击重复入栈，立即有按下/正在打开反馈；首帧不提前挂载未使用的草案编辑抽屉。重访保留历史阅读位置，不用动画掩盖网络失败。

## 设计与验收

保留纸材、玉绿、头像、B6 几何；复用 uni-icons、DeviceSheet 与现有日历。新增组件限于三个页面共同使用的导航栏，不引入依赖或业务管理表单。局部搜索立即切换，transform/opacity 过渡不超过 260ms，保留 reduced-motion。

沿真实微信组件操作验证主页面循环、无栈返回、系统返回关闭层、三级 pane、搜索/参数返回、失败重试、重复点击、输入/阅读状态恢复。成功数据使用隔离 UI 夹具，所有保存/确认请求均拦截为本地响应并明确标注；不启动真实设备调度或下发控制。模拟器不能代替真机手势/生产 H5 验收。既有公开行为测试及微信编译通过后作一次 Standards/Spec 审查、提交和交接。
