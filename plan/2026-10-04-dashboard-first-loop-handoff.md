# A 原生仪表盘与双入口交接

日期：2026-10-04。当前记录票 09 的首条闭环，不代表周期任务、Company 控制或完整统计报表已交付。范围以 [最新推进目的](2026-10-04-demonstration-delivery-handoff.md)与本地票 09 的 Frozen first loop 为准。

## 已实现

物联助手菜单打开 A 原生仪表盘：玉绿园区示意、当前接入观察目录的数量、环境读数、最新计量功率、独立维修演示曲线与安全台账。底部公司 Agent 按钮进入现有对话；Office 通过二级入口进入，两端返回总览并沿既有机制保存各自会话/草稿。没有替换小程序首页，也没有另建对话引擎。

Runtime 新只读接口 `GET /api/agent/dashboard?source=company` 经既有账户核验并只读 Company 观察范围。前端详情复用 ObservationCard/DeviceSheet/AgentAvatar；请求被替换或页面隐藏后不应用迟到结果，身份变化/读取失败清理旧概览。没有新依赖、模型调用、控制、通知或扫描服务。

## 数据与展示边界

- “已接入观察设备”不是公司全部设备数；园区 SVG 是示意图，不是设备地理定位。
- `totalActivePower` 显示 kW 最新已知功率，并保留上报时点/陈旧或未知时间说明，不累加成日用电 kWh。
- “维修演示”是一组明确标记的 24 小时典型日 kWh 样例，日合计 938、最高小时 82，均由数据计算，图形随数据计算。可切到真实计量读数；后台真实读取始终执行，演示数据不回传或进入执行上下文。
- 环境取一个可读传感器并显示其名称/来源，不虚构全公司平均。影子值有说明，缺字段显示未知。
- 台账总数表示有分页上限的读取器本次返回记录，详情显示最近 8 条；接口没有时间窗，不虚构“近 0 天”或“本次窗口”。读取失败显示暂不可用，不冒充零事件；平台标记不当成已恢复。
- 当前没有填充虚构自动化摘要；Company 周期报告/任务摘要随自动化切片接入。
