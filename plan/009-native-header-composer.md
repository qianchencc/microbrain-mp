# 原生顶部栏与输入栏

> **2026-09-14 修订：** 桌面微信开发者工具当前可用。下文“开发者工具登录失效”的描述只记录当时验收条件，不再是当前阻塞项；应在下一轮原生端到端验收中重新检查本组件。

2026-09-09。范围：独立原生小程序 apps/agent-miniapp；未修改客户首页或浏览器版。

顶部取消独占一行的在线状态，品牌、状态点和会话入口收在同一导航栏；按微信胶囊实际位置留出空间。点击标题复用原生 ActionSheet，清除继续沿用既有确认弹窗。

输入栏改为浅色细边、柔和阴影与绿色圆形发送按钮；保留原生 textarea 的多行输入、键盘发送和键盘高度处理。切换语音保留文字草稿，录音区提供启动、录音、上滑取消、识别反馈；识别完成通过既有消息接口发送文字。后台中断录音，取消结果不得提交。

语音使用客户现有 WechatSI 插件的延迟适配。当前测试 AppID 未注册插件，实际录音识别未验收；按住时会提示使用文字输入，不会假装识别成功。客户插件登记见独立项目 README。

验证：31 项测试通过，包含录音启动/松手竞态、取消、离开页面和插件缺失。2026-09-14 构建脚本已改为调用 HBuilderX 随附的 Node，默认 Node 26 不再触发编译缓存不兼容；`npm run test:weixin` 可重复完成构建和产物测试。桌面开发者工具登录和模拟器控制闭环已经恢复；真机键盘和真实语音仍未验收。

设计依据：沿用 emil-design-eng 的克制材质、短按反馈、稳定控件位置和 reduced-motion 处理。没有新增 UI 依赖。
