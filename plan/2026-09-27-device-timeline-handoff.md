# 设备时间轴交接

2026-09-27。范围为区域工作台票 11：设备抽屉中的设备历史、设备日历，以及设备记录返回所属 Task 详情。不新增人工操作来源，也不写入设备或 Task 数据。

## 业务结果

- 点区域设备卡，在同一高抽屉内进入设备视图；保留返回设备列表。设备页继承区域时间轴当前日期，展示设备图片、位置与最后已知状态。设备日历只标记该设备有阶段记录的日期。
- 设备记录由现有 Task 阶段设备表投影，按当前用户设备授权读取；未授权设备 404。单阶段为时间点，同一任务同日双阶段合成 B6 单侧区间，卡片显示来源、目标变化、结果和发起人，点开同一任务详情抽屉，关闭后保留设备轴位置。
- 结果短文案区分已核验、已满足、待核验、结果未知、未受理、部分完成与待执行。设备迁区后，当前仍有设备权限的用户可以查看其历史与所属 Task 详情；详情只返回他当前有权看的设备，旧区域时间轴仍要求原区域授权。
- 开发版“查看样例”模式可为当前选择的照明或空调生成本地单点/双阶段记录，用于微信视觉与导航验收；样例带显式标识，正式模式只请求真实 Runtime。

- 唯一 3200 Runtime 已在 production 模式直连客户网关；真实库当前没有新 Task，因此真实设备的非空历史和真机拖拽仍待票 04 的明确确认操作后验收。样例不等于真实操作证据。
