# 任务管理中心重做（B 日期议程）生产实现

状态：2026-10-22 用户认可 HTML 原型 B 方案并要求落地生产；「收件箱」按用户要求统一改名「通知中心」。原型在同级仓库 `mp-task-center-prototype`（分支提交 `8917811`、`311b24c`），本轮按原型的信息结构在生产组件上实现，未照搬原型 mock 逻辑。

## 范围与命名

- 公司仪表盘底部任务块：`CompanyTaskOverview` 由紧凑周日历改为「接下来」小议程预览（日期轨道 + 时刻 + 完整名称 + 状态，周期行副行直接写触发规则），标题「任务管理」，单一出口「查看所有任务 ›」。
- `TaskListSheet`（company）：分段「全部任务 / 日历」，通知中心为顶栏图标入口（带未读角标），周期计划为全部任务内叠层（条带 → 计划列表 → 计划详情），标题「任务管理」。Office 视图（待执行/执行结果/周期计划）保持原结构，仅放开待执行对周期发生的过滤，使所有定时任务可见。
- 通知中心：`TaskInboxContent`、`TaskInboxSheet`、`agent-menu` 及总览入口的全部「收件箱」文案改名；打开消息 → 原任务 → 报告 → 逐级返回与已读语义不变，API 未改。

## 数据与周期启停语义

- 「全部任务」由 `listAgentTasks(from=今日, to=今日+371天)` 一次取回，含物化发生与虚拟投影（`occurrence`/`repeat`），前端不自行推导投影；已停计划不发生，其已生成/执行中/历史任务作为普通任务行继续出现，与 Runtime 语义一致。
- 议程分组为纯函数 `agendaGroups(tasks, today, dayCount)`：前 10 个自然日分组（含空日，全部为空时收敛为一行说明）+ 「更晚」桶（首个发生日期 > 第 10 天且未在分组中出现的任务，带各自日期，去重）。
- 总览预览复用同一分组，只取未结束状态（`taskSettled` 排除 completed/verified/cancelled/satisfied），每日 ≤3 行、合计 ≤4 行，超出显示「还有 N 项」；执行中 5 秒、其余 30 秒轮询，沿用日历的代次/身份/可见性守卫。
- 计划启停仍走既有 `setTaskPlanStatus`（pause/resume + 用户确认 + version）：停用只影响未来发生，当前发生不回滚；启用重新核验范围与绑定，不补过去。同一开关出现在计划列表与计划详情，状态由 `plan.status` 字段判定，不再由 `nextAt` 推断「待确认」假态。
- 加载与失败：计划未加载时条带显示「读取中…」，不显示假开关/假计数；任务读取失败显示紧凑「任务暂未加载/更新」+ 重试 + 「查看原因」系统弹窗（沿用 2026-10-15 约定）；刷新失败保留旧快照并追加单行错误；计划失败不阻塞任务议程（条带显示「未能加载」，进入计划页可重试）。

## 实现细节

- `view` 取值：company 为 `all`（默认）/`calendar`/`inbox`/`plans`，后两者为叠层视图（`stackedView`），返回键逐层回 `all`；旧 `initialView: 'schedule'` 兼容映射为 `all`。
- 计划列表请求独立 `loadPlans`/`plansError`/`plansLoaded`（ref，原 `let` 进模板不响应已修正），任务列表 `taskRows` 缓存与 requestId 守卫不变；`onHide`/身份切换作废在途请求。
- 行交互：议程行点按与日历行一致进 `TaskResultContent`（company 统一传 `{id}` 按 ID 重取）；虚拟发生沿用既有 `occurrence:` ID 深链。周期行副行 `周期 · <repeatText>`，时间由行首时刻承担，名称保持完整换行不删字。
- 未改 `dashboard.vue`（emit 形状不变，且其中有他人未提交改动）；未改 Runtime、API 形状、通知已读逻辑、任务详情/报告宿主。

## 边界与待验收

- 「全部任务」取一年窗口是列表可见性口径，真实年度虚拟行规模取决于 Runtime 返回，未在真机量测；若 Runtime 另有上限，超出部分仍只能在更晚桶内出现到窗口为止。
- Office「待执行」放开周期发生是按「看到所有定时任务」要求的最小改动，未重做 Office 视图结构；若产品想保持原过滤可单行回退。
- 微信原生验收（开合、返回栈、开关确认弹窗、横滑段控件、通知已读）未执行；源码与编译通过不等于真机验收。真机验收建议覆盖：停用计划后执行中任务保留且未来投影消失、启用确认流程、通知中心消息 → 报告 → 返回、刷新失败保留快照、320px 窄屏无横向溢出。
