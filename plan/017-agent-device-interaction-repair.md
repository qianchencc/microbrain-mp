# 物联 Agent 设备交互修复

日期：2026-09-15

## 目标

将设备卡片、长按配置、底部配置面板和输入区恢复成一条可理解、可触控、可验收的原生小程序交互链路，并修复历史态残留编辑器和缺失图标。

## 已完成

- 卡片短按选择、长按配置分流，长按进度使用共享常量；
- 选中卡片、确认草案、输入区使用静态 SVG 图标，避免 `uni-icons` 在当前构建中的空白 glyph；
- 配置面板层级提升到输入栏之上，并在草案不再待确认时卸载；
- 只有存在多个同类设备时才显示批量应用开关；
- Agent 头像恢复为固定 seed 的 Blobatar 生成结果；
- 确认与取消按钮补齐手机触控反馈和 44px 最小触控高度。

## 验收证据

- `npm test`：源码行为测试；
- `npm run test:weixin`：微信构建及编译产物头像加载测试；
- 微信开发者工具：选中/取消选中、图标可见、配置面板层级、历史态不残留、控制台无新增错误。

## 明确不在本次范围

- 不执行真实设备控制；
- 不重写草案确认后的执行语义；
- 不重新设计 Agent 回复编排和后端流式协议。
