# Agent 统一回复表面闭环

日期：2026-09-15

## 结果

一轮 Agent 回复已统一由 `AgentReplySurface.vue` 编排身份、处理记录、流式正文、操作草案、执行收尾和错误状态。用户消息仍由 `UserMessage.vue` 独立负责，操作草案内部逻辑未改动。

| Before | After | Why |
| --- | --- | --- |
| 页面模板直接拼接头像、状态、轨迹、正文、草案和回执 | 单一 `AgentReplySurface` 负责整条 Agent 回复 | 保证各状态属于同一消息，而不是多个散落区块 |
| 头像按会话随机生成，可能出现粉色三角等不合品牌的形状 | 固定绿色品牌头像，保留轻微眼神与呼吸反馈 | 产品身份稳定，不随会话漂移 |
| 正文和草案长期为旧头像侧栏预留 46px | 身份行在上，正文、轨迹和草案使用完整消息宽度 | 原生手机窄屏减少无效折行，草案卡片获得更合理宽度 |
| 处理记录是页面里的裸按钮和独立轨迹块 | 收拢为同一柔和表面；正文开始后自动收起，可再次展开 | 保持信息层级并减少视觉割裂 |
| 原生包保留 `blobatar` 与编码 polyfill | 移除两个不再需要的依赖 | 降低随机视觉和原生启动依赖复杂度 |

## 边界

本闭环没有修改 `ActionDraftCard`、设备卡片、参数 Sheet、Runtime 控制语义或 Agent prompt。后续若继续优化，应单独处理 ReplySurface 的状态图标 cross-fade 与工具节点进入动效，避免把视觉动效和业务状态机混在一起。
