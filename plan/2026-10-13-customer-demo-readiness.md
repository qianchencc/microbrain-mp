## 三、推荐演示链路（一条主链，约 12–15 分钟）

主线：公司管理者视角，“看态势 → 查异常 → 看现场 → 做控制 → 定自动化 → 收结果”。

1. **仪表盘**：物联助手入口 → A 总览（环境、电表累计示数、安全台账、摘要）。
2. **观察**：Company Agent 问“26 楼现在温度和空气质量怎么样” → 观察卡（真实读数 + 采样时间）；追问“最近 24 小时趋势” → 趋势卡。
3. **安全台账**：烟感分类列表 → 点开一条详情 → 引用到输入框 → 发送“这条怎么回事” → 基于同一记录回答 + 关联录像候选。
4. **视频**：观察卡“查看画面” → H5 播放页实时观看 → 返回；再演示定点录像回放。
5. **即时控制**：“把 26 楼运营部的空调调到 26 度” → 草案卡（设备、参数、回读计划）→ 确认 → 执行收据。
6. **自动化**：“工作日 18:30 关闭运营部空调” → 周期计划卡 → 确认 → 我的安排/时间轴看未来发生。
7. **闭环**：安排一个 2–3 分钟后的一次性任务 → 到点执行 → 收件箱结束消息 → 打开同一报告 → 引用追问（“这次结果怎么样”）或修改（“改到 18:45”→确认）。

可选副线（Office 员工视角，3–5 分钟）：
- “26 楼办公区楼道的灯，5 分钟后帮我开一下” → 候选列表 → 回复“后者” → 指代映射 → 任务卡 → 确认 → 区域工作台时间轴 → 到点报告。
