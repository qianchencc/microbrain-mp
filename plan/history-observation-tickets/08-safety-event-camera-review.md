# 08 — 安全事件引用到候选监控与回放

Date: 2026-10-09
Status: ready-for-agent
Blocked by: 01, 04
External/decision gates: 无新权限系统或强制新关联接口；沿 E02 保留视频真机边界。

规格：[历史观察与双 Agent 视频](../2026-10-09-history-observation-spec.md)。状态是发布时快照，实施进展在本地 tracker 同编号票维护。

## What to build

用户在安全记录详情或 Company 引用后询问前后画面，系统按地点给本端候选摄像头，用户选择后打开明确录像窗口并能返回原事件。

## Frozen scope

复用已验证区域/安装地址与客户实际摄像头上下文，不宣称同名地点等于精确覆盖。过去记录时间只作窗口依据，不升级为精确物理报警时刻。

## Expected code size

Runtime 80–160，mp 100–160 行。 估算只含新增/主要修改的生产逻辑，不含固定倍数的测试或文档，也不是报价。开工先核对现有实现；明显超出应说明原因并缩小本票，禁止顺手扩大为平台。

## Acceptance criteria

- [ ] 同一事件身份/记录时间保留，找监控只使用 Company 本端目录。
- [ ] 候选列表说明地点依据，存在多台时用户选择；无匹配或无录像诚实说明。
- [ ] 前后窗口明确可审阅并满足回放限制，进入/重试/返回保留原事件与摄像头。
- [ ] 引用不覆盖原草稿、不自动发送、观看不产生消防处置或物理动作。
- [ ] 真实台账→引用追问→选候选→近期可播录像或明确超保留期结果的微信路径留证。
- [ ] 必要测试/类型/构建、微信编译和本票实际操作证据通过；真实接口、模拟器、真机边界分别记录。
- [ ] 必要稳定切片审查、语义提交、plan 交接完成；外部验收未通过不得标整票完成。

## Testing decisions

公开 Company 对话流承接真实安全 reference 与候选摄像头；实际微信选择、回放、返回验证；复用已完成安全/回放测试，不再复制整套协议矩阵。

## Out of scope

不新增本票之外的控制、通知、权限或通用平台。未决项只阻塞这里列出的业务行为，不反向阻塞已可开始的历史查询。
