# 07 — 可解释的公司电量比较与期间报表

Date: 2026-10-09
Status: needs-info
Blocked by: 06
External/decision gates: E03：明确不重叠计量集合与区域映射；原始数值相等不构成汇总证据。

规格：[历史观察与双 Agent 视频](../2026-10-09-history-observation-spec.md)。状态是发布时快照，实施进展在本地 tracker 同编号票维护。

## What to build

用户在已确定计量集合内比较两个期间、看逐表排名与公司汇总报告；仪表盘和 Company 可以继续解释变化及缺失覆盖。

## Frozen scope

集合明确后才汇总，复用单表统计。不自动建定时报表/导出/外推；集合不明仍可逐表展示，但不能以此关闭公司汇总票。

## Expected code size

Runtime 180–320，mp 120–200 行。 估算只含新增/主要修改的生产逻辑，不含固定倍数的测试或文档，也不是报价。开工先核对现有实现；明显超出应说明原因并缩小本票，禁止顺手扩大为平台。

## Acceptance criteria

- [ ] E03 集合成员、重叠判断依据及区域范围已留证；拒绝把全目录计量点简单相加。
- [ ] 各期同字段/单位/倍率，覆盖差异、缺表与部分结果附报告；基期零不伪造同比百分比。
- [ ] 排名和汇总基于实际区间电量，未核实区域不从同名位置硬拼。
- [ ] 仪表盘/Company 同一集合比较结果一致，报告范围与真实/演示标签贯穿追问和恢复。
- [ ] 实际集合下的历史双期间对比与微信图表/报告解释完成；当前采集中断明确保留。
- [ ] 局部门槛收口后才进入生产实现；必要测试/类型/构建、微信编译和本票实际操作证据通过；真实接口、模拟器、真机边界分别记录。
- [ ] 必要稳定切片审查、语义提交、plan 交接完成；外部验收未通过不得标整票完成。

## Testing decisions

公开汇总/对话报告，夹具制造上级/分表重叠、缺表、单位不一致、零基期和部分覆盖；真实历史报告与逐表证据对账。

## Out of scope

不新增本票之外的控制、通知、权限或通用平台。未决项只阻塞这里列出的业务行为，不反向阻塞已可开始的历史查询。
