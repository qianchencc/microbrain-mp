# 02 — 公司环境趋势与对话追问

Date: 2026-10-09
Status: ready-for-agent
Blocked by: None (can start immediately)
External/decision gates: None；历史可读。颗粒物单位未核实时保留未知，不阻止趋势读取。

规格：[历史观察与双 Agent 视频](../2026-10-09-history-observation-spec.md)。状态是发布时快照，实施进展在本地 tracker 同编号票维护。

## What to build

用户从仪表盘环境进入趋势、切指标和日期，或向 Company 询问同一窗口；看到真实采样、变化与峰值并继续追问。

## Frozen scope

站点级历史与既有实时观测分开标识；统一 PM 语义，tem/hum 正确映射。复用观察结果持久化与 Sheet，优先已有 SVG 图形方式，不建通用图表平台。

## Expected code size

Runtime 260–420，mp 260–440 行。 估算只含新增/主要修改的生产逻辑，不含固定倍数的测试或文档，也不是报价。开工先核对现有实现；明显超出应说明原因并缩小本票，禁止顺手扩大为平台。

## Acceptance criteria

- [ ] 实时/历史的 pm101 显示 PM10、pm10 显示 PM1.0、pm25 显示 PM2.5；旧原始事件值不被重写。
- [ ] 空设备标识只显示站点观测；窗口外记录不进入曲线，缺失值不补零、不连成虚假连续采样。
- [ ] Company 与仪表盘对相同窗口/指标给出一致采样、覆盖与峰值；后续追问保持该窗口。
- [ ] 切日期/指标、空数据、网络失败和返回恢复可操作，其他概览不等趋势。
- [ ] 真实时间窗与实际微信趋势/追问/恢复留证据；显示本次读取时间及历史记录时间的区别。
- [ ] 必要测试/类型/构建、微信编译和本票实际操作证据通过；真实接口、模拟器、真机边界分别记录。
- [ ] 必要稳定切片审查、语义提交、plan 交接完成；外部验收未通过不得标整票完成。

## Testing decisions

环境历史公开 GET + Company 消息流/恢复；生产协议夹具覆盖错 PM 标签、null 标识、空窗口与缺点；界面实际点击/坐标数值核对。

## Out of scope

不新增本票之外的控制、通知、权限或通用平台。未决项只阻塞这里列出的业务行为，不反向阻塞已可开始的历史查询。
