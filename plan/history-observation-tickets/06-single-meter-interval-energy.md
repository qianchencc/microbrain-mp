# 06 — 单计量点区间电量与解释

Date: 2026-10-09
Status: needs-info
Blocked by: 05
External/decision gates: E01：计量方向/字段、单位倍率、有效边界与清零规则，收口前不实施派生统计。

规格：[历史观察与双 Agent 视频](../2026-10-09-history-observation-spec.md)。状态是发布时快照，实施进展在本地 tracker 同编号票维护。

## What to build

用户查询一个计量点的时段电量，仪表盘和 Company 返回同一可信差值及实际边界采样，能追问为何覆盖不足或结果异常。

## Frozen scope

只做单表计算与可查看报告，复用原始历史读取/卡片。负增量、零基期、无边界返回可解释结果，不另建通用计算引擎。

## Expected code size

Runtime 180–280，mp 80–160 行。 估算只含新增/主要修改的生产逻辑，不含固定倍数的测试或文档，也不是报价。开工先核对现有实现；明显超出应说明原因并缩小本票，禁止顺手扩大为平台。

## Acceptance criteria

- [ ] E01 证据和采用口径写回规格/票据；字段、方向、单位、倍率可由结果查明。
- [ ] 结果附实际开始/结束采样时间和值、请求范围及有效覆盖，缺边界不称完整日耗电。
- [ ] 负增量/清零/换表/同时间冲突不被取绝对值、补零或抹除；未知时不给假精确数。
- [ ] 仪表盘与 Company 同一输入得同一计算，追问继承范围，恢复保留报告事实。
- [ ] 可用历史样本与原始边界人工对照、真实微信报告/异常说明通过。
- [ ] 局部门槛收口后才进入生产实现；必要测试/类型/构建、微信编译和本票实际操作证据通过；真实接口、模拟器、真机边界分别记录。
- [ ] 必要稳定切片审查、语义提交、plan 交接完成；外部验收未通过不得标整票完成。

## Testing decisions

公开 energy-summary GET 及消息流，用已冻口径覆盖正常差值、部分边界、负增量、倍率、零基期和源拒绝；不直接测试私有计算过程。

## Out of scope

不新增本票之外的控制、通知、权限或通用平台。未决项只阻塞这里列出的业务行为，不反向阻塞已可开始的历史查询。
