# 04 — 双 Agent 录像窗口与回放

Date: 2026-10-09
Status: ready-for-agent
Blocked by: 03
External/decision gates: E02；开工先在隔离验证页证明 SDK 回放调用，保留时长未知只限制承诺范围。

规格：[历史观察与双 Agent 视频](../2026-10-09-history-observation-spec.md)。状态是发布时快照，实施进展在本地 tracker 同编号票维护。

## What to build

用户在两端指定摄像头与录像时间，通过回放卡进入共用播放器，查看真实录像并在失败、重试、返回时保留原窗口。

## Frozen scope

基于已授权设备 hub 绑定调用新回放动作；单次窗口最多三天，超过时提示调整而非悄悄截断。只开放经 SDK 实测的控件，动作 ID 留在适配器，不把直播参数当回放协议。

## Expected code size

Runtime 180–280，mp/H5 220–420 行。 估算只含新增/主要修改的生产逻辑，不含固定倍数的测试或文档，也不是报价。开工先核对现有实现；明显超出应说明原因并缩小本票，禁止顺手扩大为平台。

## Acceptance criteria

- [ ] 有明确 source、摄像头、beginTime/endTime；结束晚于开始、时区明确、窗口上限公开校验。
- [ ] 实时离线不阻断历史回放；模式标题、录像 OSD/时间与 LIVE 区分。
- [ ] 以近期有录像窗口证明实际首帧与已开放控件；空录像/过期/频控/解码失败有不同结果。
- [ ] 重试和换窗口不丢 source，先释放旧会话；返回恢复原日期/卡片/输入。
- [ ] 会话恢复只保留设备与录像窗口，点击现取短期地址；E02 未满足时生产验收不标通过。
- [ ] 必要测试/类型/构建、微信编译和本票实际操作证据通过；真实接口、模拟器、真机边界分别记录。
- [ ] 必要稳定切片审查、语义提交、plan 交接完成；外部验收未通过不得标整票完成。

## Testing decisions

公开取流 GET 的回放参数、两端范围和不可用结果；生产协议 fixture 与 SDK 真实近期录像/微信点击分别验收。取流返回 WSS 只算接口证据。

## Out of scope

不新增本票之外的控制、通知、权限或通用平台。未决项只阻塞这里列出的业务行为，不反向阻塞已可开始的历史查询。
