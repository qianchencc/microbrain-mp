# 01 — 三类安全历史列表、详情与引用

Date: 2026-10-09
Status: ready-for-agent
Blocked by: None (can start immediately)
External/decision gates: None；现有 Company 安全目录与详情引用已可复用。

规格：[历史观察与双 Agent 视频](../2026-10-09-history-observation-spec.md)。状态是发布时快照，实施进展在本地 tracker 同编号票维护。

## What to build

用户在仪表盘或 Company 查询烟感、水浸、燃气历史，筛选并翻页，点击单条详情，保留草稿引用到对话，得到同一事件的解释。

## Frozen scope

接独立 smoke 台账；新列表分类排除 flooding 中已确定的烟感污染，未知分类单独说明；旧引用沿原 ledger/eventId/deviceId 追溯。复用现有来源与详情，不新建告警表或处置状态机。

## Expected code size

Runtime 180–320，mp 180–280 行。 估算只含新增/主要修改的生产逻辑，不含固定倍数的测试或文档，也不是报价。开工先核对现有实现；明显超出应说明原因并缩小本票，禁止顺手扩大为平台。

## Acceptance criteria

- [ ] 三类筛选读取对应台账；固定窗口翻页不重复事件，未完成扫描不伪称精确全量。
- [ ] 新 smoke 详情与引用可用，旧 flooding 烟感引用恢复/重试仍可追溯原记录。
- [ ] 范围外设备、错来源与失效身份不可读；上报标记、历史记录和当前恢复状态分别表达。
- [ ] 列表壳、返回和引用无需等待全量统计；原输入不丢、不自动发送，切筛选后旧响应不覆盖新列表。
- [ ] Company 真实台账→详情→引用→发送→重新进入流程留下实际微信证据；旧年份记录明确标注。
- [ ] 必要测试/类型/构建、微信编译和本票实际操作证据通过；真实接口、模拟器、真机边界分别记录。
- [ ] 必要稳定切片审查、语义提交、plan 交接完成；外部验收未通过不得标整票完成。

## Testing decisions

公开安全列表/详情 GET 和消息 NDJSON；扩展现有安全引用恢复场景，制造独立 smoke、混表、分页及故障记录。真实只读核对分类后再做微信操作。

## Out of scope

不新增本票之外的控制、通知、权限或通用平台。未决项只阻塞这里列出的业务行为，不反向阻塞已可开始的历史查询。
