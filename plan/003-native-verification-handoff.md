## Working Native Automation

Official miniprogram-automator 0.12.1 is installed only in `/tmp/native-automator.At2foQ`, not the application's dependencies. Its temporary scripts use the real native component event interface, not page state injection. `inspect.cjs` launches the compiled independent project with the existing developer tools, port 9420. Subsequent scripts connect and disconnect without closing the application.

- `check.cjs`: revalidate the test draft, no execution.
- `browser.cjs`: open all devices and screenshot.
- `check-page.cjs`: open/revalidate as needed, long-hold an AC, inspect swiper index and screenshot.
- `navigation.cjs`: back to list, long-hold door, assert page 1 both before and after release, navigate both directions.
- `save-door.cjs`, `save-ac.cjs`: edit same-type scope and save only. Avoid replaying without inspecting current draft state and values.

Run with `/opt/homebrew/opt/node@22/bin/node`. Scripts contain observed component IDs for the existing test conversation, so inspect WXML again if the turn list changes. Page CSS selectors cannot traverse custom-component roots; `page.xpath` can locate rendered inner controls. Official SDK `touchstart`, `touchend`, `input`, `tap`, and `swipeTo` work. DOM click via CDP does not reliably trigger native tap.

Drafts expire after five minutes; tests must revalidate and run promptly. Never extend production expiry just for verification. The latest mixed test draft was edited but not executed. No conversation clearing occurred.
