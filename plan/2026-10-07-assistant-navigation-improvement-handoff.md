# 物联助手导航改进交接

2026-10-07；实施基线 `c600229`。用户授权“按照要求检查并完成改进”，范围是物联助手全部页面及临时层的导航体验。当前已完成代码改进、微信编译、模拟器夹具走查及一次 Standards/Spec 审查；真实手机手势、生产恢复延迟和 H5 播放仍需外部环境验收。

权威范围见 [规格](2026-10-07-assistant-navigation-improvement-spec.md)；改造前树和 29 类入口见 [原检查](2026-10-07-page-navigation-audit.md)；[实际截图与逐场景结果](../docs/research/assistant-navigation-review/after/README.md)和[画面对照](../docs/research/assistant-navigation-review/after/index.html)保留证据。历史检查文档不改写成实施结果。

## 最终空间与返回规则

```text
客户服务首页（模块边界）
└─ 公司运行总览 / dashboard
   ├─ 公司 Agent / index?source=company
   │  ├─ 会话菜单、输入/编辑、观察卡
   │  └─ 概览/草案 → 全部设备/搜索 → 参数
   ├─ 办公室 Agent / index?source=office
   │  ├─ 关注区域选择；会话/输入/草案层同上，来源隔离
   │  └─ 区域工作台 / region
   │     ├─ 区域日历、独立任务/报告抽屉
   │     └─ 设备抽屉 → 设备时间轴/观察详情 → 同一任务报告
   │        └─ 设备日期浮层；观察设备 → 专用视频 WebView/H5
   └─ 环境、计量、安全台账观察抽屉
```

树决定默认父页，实际进入历史决定正常返回。来源创建时固定；Company/Office 同级入口集中在总览，会话菜单只管理会话。未新增计划页、Company 工作台、收件箱或底部 tab。

- 三个原生路由共用 `AssistantNav`：返回触区 44px、常驻页面名、独立会话入口、微信胶囊留空。区域名负责选区，办公室另有“工作台”入口。
- 页面返回有历史则 navigateBack；无历史 redirect 默认父页。总览的父页为服务首页，工作台为 Office。“新建任务”明确定位 Office，而不是随便退一页。
- DeviceSheet 的 X 关闭整层；多级抽屉左箭头与微信返回退当前一层。设备日期浮层先收起，然后才回设备列表。日历通过组件 ref 暴露 dismiss，由所属抽屉统一分派；视觉遮罩/横杆/transform/opacity 保留原底座。
- 明确关闭整个设备抽屉后再打开从列表开始；临时跨页/onHide 则保存设备、任务、搜索及日期路径，暂停后台刷新。正常 onShow 重读授权目录；删除/撤权的设备不保留旧 pane。
- 参数离开只有真实脏值才询问；保存/放弃回原搜索或列表，失败保留修改。确认错误留抽屉现场，不展示假“已执行”，允许读取回执。任务“取消”与退出抽屉分开，历史/执行事实保留。
- 对话按 scope+source 保存阅读位置、原新消息草稿、编辑中的原轮文本；换身份立即清旧视图，异步响应再复核身份，拒绝时清旧任务。恢复需要 conversationId/turnId 匹配。

- `npm run test:agent`：24/24；新增测试从公开导航调用与作用域草稿接口验证，未新增源代码/CSS 正则断言。

- Standards 审查发现换身份旧会话、隐藏任务旧报告、退出动画空白；Spec 审查发现重复任务跳转与原始确认错误。已分别修正。日历返回分派收尾改动作限定复核，按 calMounted 消费整个进退场窗口，避免快速返回穿透设备 pane。
- 未启动 Runtime 3200、scanner、真实模型请求、控制或通知。H5 专用分支以外客户页面未改；共享 WebView 只过滤本批 assistantVideo 标记并设置专用标题。

## 真机与生产验收入口

用更新后的微信包验证：公司/办公室进出；390/320 窄屏标题与胶囊；设备→任务→返回设备→列表；打开日历后侧滑/实体返回；横杆连续开合及脏值取消；搜索/参数保存；网络断开后的确认回执读取；编辑/阅读重访；配置视频页后的真实 WebView 往返。速度需分别测点击反馈、原生 route、首渲染及恢复请求，生产与开发模式分开。

修真机差异时优先保留上述空间/退出契约；不要恢复混合会话导航菜单、清栈 reLaunch 或第二套设备/任务事实。当前六个旧探索文件保持未跟踪，未混入提交；业务原型 worktree 继续暂停，Runtime 并行业务不受本批影响。
