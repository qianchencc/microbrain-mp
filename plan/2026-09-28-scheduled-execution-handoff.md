# 定时任务到点执行交接

日期：2026-09-28。范围：区域工作台票 07；设计依据 `.scratch/region-workbench/issues/07-scheduled-execution.md` 与 ADR 0004。

## 已接通

- Runtime 生产启动后立即扫描一次，之后每 15 秒扫描。任务确认时若首阶段已到期且仍在 10 分钟窗口内，立即触发扫描。阶段 CAS 认领；超窗记 `missed`；前一阶段失败或错过不阻断下一阶段。
- 执行时解密创建者凭据，强制重新读取当前授权目录；设备撤权/消失记 `missing`。复用 `executeDevices`：先读全部设备、已达标不下发、其余按目标控制并回读。逐设备收据与权威回读保存到 Task 阶段；任务 `completed/partial/failed/missed/interrupted` 由阶段事实汇总，终态删除托管凭据。
- 目录读取、状态读取和控制遇上游 401/403 可标识创建者登录失效；已进入下发阶段的异常保留“结果未知/执行中断”，不得谎称未下发。扫描有超时和并发上限；关闭先中止并等待扫描收口，再关闭数据库。启动残留 `executing` 阶段转中断且不补跑。
- 对话任务卡、区域时间轴、任务详情和设备记录显示执行中、已错过、中断、部分完成及逐设备结果；页面可见时静默刷新，避免停留页面时状态冻结。
