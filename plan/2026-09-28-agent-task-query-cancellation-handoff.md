# Agent 查询与取消任务交接

日期：2026-09-28。范围：区域工作台票 09；依据 `.scratch/region-workbench/issues/09-agent-queries-and-cancels.md`。

## 已接通

- Agent `list_tasks` 按授权区域和上海日界只读查询任务；模型只获得当前授权区域的名称与 ID，查询结果不含凭据或跨区域任务。`propose_task_cancellation` 必须引用本轮查出的精确任务 ID，且任务仍有待执行阶段、调用者覆盖全部设备。
- 取消提案拥有独立 `cancellationId`、目标 `taskId`、目标版本、过期时间和剩余阶段快照。下一条消息或放弃只退役提案；确认时 fresh 重读授权范围并复用工作台取消事务。任务版本变化时旧卡过期，已执行动作不回滚。
- 对话卡区分创建与取消，创建收据和取消收据都可恢复；确认后显示已取消，并可打开区域任务记录。

## 验证与边界

- Runtime HTTP 场景覆盖只读查询、提案不执行、零滞留、越权、授权变化、确认后取消和旧卡版本冲突；小程序会话测试覆盖同一任务两张收据恢复。所有设备动作仅在隔离网关夹具中发生。
- 客户小程序的自然语言效果、卡片布局和真实操作验收由用户完成；本轮没有在真实网关取消任务或控制设备。
- 后续票 12/13 分别处理区域异常提示/已查看与真实创建者名称；票 14 的设备控制验收需用户明确指定具体设备与时间。
