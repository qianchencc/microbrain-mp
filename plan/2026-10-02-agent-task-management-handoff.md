# Agent 管理与任务引用交接

日期：2026-10-02。状态：用户已认可前台简化方向与本轮引用交互建议，待可操作原型验证。未修改生产代码或原型代码。

## 已接受的范围

复杂业务操作交给 Agent。任务前台保留查看、删除与任务引用，不提供创建/编辑表单、检查点编辑器、作用范围选择器或手动启停管理入口。Agent 继续负责创建、修改、启停等基础能力的编排与提案；用户确认后才能写入。原有操作权限、设备范围复核、版本冲突和历史不变约束保留。

实际 Task 的“删除”表示取消未执行部分、保留执行历史；删除周期计划停止未来发生、保留已发生记录。删除对象与影响必须明确，不把删除计划误当作取消当前发生。

## 推荐的最小引用体验

任务详情提供次级按钮“交给 Agent”，与“删除任务”区分。点击后关闭任务抽屉，返回现有 Agent 页面，在输入框上方显示一条可移除的引用条，例如“会议室准备 · 10 月 3 日 14:00–16:00”。保留已有输入草稿，聚焦输入框；不自动发送、不预填某种修改操作。

只需一条当前任务引用，不建设多对象引用管理器。用户可输入“只把明天这次推迟半小时”“以后都改成十九点半”“解释这次为什么部分完成”。任务详情仍承担只读展开，不在引用条中另造编辑器。

| 场景 | 预期结果 |
|---|---|
| 输入框已有“帮我看看”，点击任务引用 | 原文本保留，新增引用条；未发送消息 |
| 引用明天的发生，输入“推迟半小时” | Agent 判断是否已明确仅本次；若作用范围不清楚则澄清，再给变更提案 |
| 引用本次，输入“以后都改成十九点半” | Agent 定位所属周期，预览未来影响；确认后生效，历史保持原快照 |
| 引用已结束记录，输入“为什么失败” | 读取本次结果与证据；不进入修改或执行 |
| 移除引用 | 用户草稿保留，后续发送不带该引用 |
| 对象已删除、失去访问权限或版本变化 | 重新核验并明确反馈；不静默按同名任务替换、不覆盖新版本 |

## 代码事实与实现约束

当前 [AgentComposer](../pages/agent/components/AgentComposer.vue) 只有文本输入、语音与消息编辑，文本上限 200 字；[Agent 页面](../pages/agent/index.vue) 使用单一输入框并保存消息编辑期间的草稿。[任务详情](../pages/agent/components/TaskDetailContent.vue) 已有详情读取和删除确认，[区域页](../pages/agent/region.vue) 支持按 taskId 打开详情。尚无任务引用传输协议；按钮跳回对话并不等于 Agent 已能识别引用对象。

引用应作为结构化上下文随本轮消息传递：实际记录使用 taskId，周期使用 planId，未落账的发生使用 planId 加发生身份；展示名称与时间仅作阅读摘要。这里只定义必要对象身份，不冻结新的 API 字段。Agent 处理时重新读取最新事实并检查权限；引用不能扩大授权范围，也不能把关注区域变成目标身份。

消息发送后固定该轮引用；重试或编辑原消息不能意外换成后来选中的对象。跨页返回、原对话存在草稿、当前处于消息编辑或运行中等组合要在原型/规格中验证；不覆盖现有消息编辑草稿，也不另外创建一套输入框。

引用条沿用现有输入框上下文静带和 Sheet 导航语言，视觉重点仍是用户输入。查看与确认提案是前台必要能力；“交给 Agent”不等于取消确认界面。

### 无需重新询问的决定

周期计划与发生分离、固定区间和自由检查点、历史不改写、未来编辑重新确认、创建者编辑/启用与完整设备权限成员停用、停用不取消当前发生、通知发创建者、订阅不足不阻断执行，均按已有决定推进。复杂操作交 Agent 不改变这些语义。已有 ADR 0003 将共享任务冲突检测移出首版，不重新引入冲突管理产品。
