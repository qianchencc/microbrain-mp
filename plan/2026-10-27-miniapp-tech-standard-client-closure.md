# 小程序技术规范客户端闭环

日期：2026-10-27

## 范围

本轮只处理小程序客户端，独立部署的 Agent 后端不纳入修改范围。

## 已完成

- 请求头改为每次请求重新构造，避免租户切换或无租户请求复用旧的 `tenantCode`。
- Token 持久化保留单一写入路径，移除重复写入。
- 账号密码登录改为可等待、可返回、可传播异常的异步流程；无有效 Token 响应时明确失败。

## 验证

- `npm run test:agent`：178 项通过。
- HBuilderX `mp-weixin` 编译：成功。

## 后续边界

小程序当前仍按客户认证服务协议携带 OAuth 客户端凭据，并在微信登录流程中调用客户 SSO。凭据是否应改为服务端代理，需要客户认证服务提供对应接口后再单独立项；本轮不通过改名、混淆或新增客户端配置来伪装解决。
