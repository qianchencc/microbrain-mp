# 定时任务创建接线交接

日期：2026-09-28。范围：区域工作台票 06，规格见 `.scratch/region-workbench/issues/06-agent-creates-scheduled-task.md` 和 ADR 0004。

## 已实现

- Runtime `propose_task` 基于完整候选集与最新能力核验生成 1–2 阶段照明/空调提案；名称、时间和设备来源在服务端再次校验。首阶段允许当前时间前 10 分钟至未来 7 天，第二阶段只需晚于首阶段。提案不执行设备操作。
- `task.proposed/task.resolved` 持久化并恢复；新消息退役待确认提案。`POST /api/agent/tasks/:id/confirm` 带版本，重核当前设备范围并阻止与新消息并发确认；成功后保存 `scheduled` Task 和加密创建者凭据。`discard` 只退役提案。
- 区域时间轴与日历可投影跨日区间；B6 当日视口裁切跨日缎带，保留真实阶段时刻。同日几何不变。
- 对话 `TaskProposalCard` 展示阶段设备目标、创建/放弃、已安排状态和区域时间轴入口；已安排/执行中按任务详情轮询，终态停止。

## 验证与边界

- Runtime 公开 HTTP 场景覆盖确认、版本与身份冲突、零滞留、并发新消息、超过 10 分钟、跨日投影、重启恢复，以及响应不泄漏凭据；全套 32 个测试、typecheck、build 通过。
- 客户小程序 `npm run test:agent` 9/9、HBuilderX 微信编译通过。编译中原有的 `pages/check/detail/index.vue` sourcemap/export 与鸿蒙提示不属本票。
- 未做小程序端视觉/交互验收，按用户分工由用户完成。未在真实网关执行设备控制，也未创建真实定时任务。
- 3200 当前仍运行旧构建；票 07 到点执行尚未接通，不能把只会保存、不执行的任务创建能力暴露为完整自动化。
