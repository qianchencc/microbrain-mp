## 两条独立业务路径

| 对象 | 产生与触达 | 用户进入后的操作 | 我方职责 |
|---|---|---|---|
| 设备告警 | 客户微脑产生，并由客户渠道通知；公众号卡片是可能形态，未定最终渠道 | 点击携完整告警内容进入 Agent 引用，用户再表达目的 | 保留内容/草稿、不自动发送；据用户目的查询、分析或提出操作；实际设备操作仍经确认 |
| 任务结束消息 | 我方已确认 Task 执行结束后保存站内消息 | 收件箱→同一次任务报告→引用/继续追问 | 消息持久化、去重、个人已读、当前授权及来源核验、返回报告 |

任务结束包括成功、部分完成、失败、中断、错过及实际取消，沿已认可终态规则；阶段进度和虚拟发生跳过不另发结束消息。收件箱不承担设备告警收集、发送、确认/指派/关闭或客户通知投递台账。此前建议增加的站内告警已读/消息阶段撤回；历史告警仍可直接查询，不转成收件箱未读。

引用携完整内容即可支持本轮解释/追问；当前本地桥是 Company 的 `alertPrompt` 和 `customer_alert` 内容引用，具体限制见[已交付交接](2026-10-04-customer-alert-reference-handoff.md)。不把客户新增处置接口、告警管理平台或摄像头关联接口作为该引用对话的前置。正式客户通知载荷、登录后返回及内容完整性按实际跳转样例联调，既有本地 2000 字限制不能悄悄截断更长的客户内容。

### 真实只读结果

使用已有开发身份及租户请求头，未重新登录，网关为 `https://ncim.577119.com`；下列路径含 `/micro-api/api`。

| 请求/样本 | 结果 | 能证明什么 |
|---|---|---|
| `/office/app/device/monitor/myAreaList`，再按返回 ID 查询子级 | 集团→26/27 楼及始版桥办公室；27 楼子级仅“全部”，`fullCode=1-2-6-10` | 区域层级存在，但本样本没有单独茶水间房间节点 |
| `/office/app/device/monitor/devicePage?areaFullCode=1-2-6-10` | code 200，13 台，包含“监控-27楼茶水间” | 可筛选 27 楼摄像头 |
| 同接口 `areaFullCode=1-2-3` | code 200，另 13 台，均为 26 楼设备 | 区域过滤真实生效；两个结果不是同一份全目录 |
| 同接口使用不存在的区域编码 | code 204，0 台 | 进一步排除过滤参数被忽略 |
| `/office/monitorAreaDevice/page?monitorAreaId=856b1b3b0e5d68c24524f1258b2fd653` | 13 条，含 `monitorAreaId/hubDeviceId/hubActionInfoId/installAddress` | 可取得区域、底层摄像头和安装位置映射；比智慧列表中的空 `installAddr` 更完整 |
| 同分页按茶水间摄像头 `hubDeviceId` 查询 | 唯一一条；`id=65f748e2265a18ab30c57d75517cc58b`，`installAddress=27楼茶水间` | 已有定位到具体茶水间监控的上游材料 |

上述检查验证接口材料，不自动把账号级目录授予 Office 或将 Company/Office 范围合并。生产接线仍沿本端身份和范围核验。

### 告警到摄像头：当前证据的边界

- `/perception/fire/flooding/alarm/page` 返回 298 条；抽样告警有 `id/deviceId/deviceName`，`elementId=null`。可据 `deviceId` 查询实际报警设备。
- `/perception/device/page` 170 条中消防三设备都指向“凯迪中心”元素；安装信息写 27 楼茶水间。不能将该楼栋级元素 ID 当成 Office 房间/区域 ID。
- 同感知目录有 24 台视频，只有 1 台 `elementId` 非空；无法直接靠这个字段给所有消防事件匹配摄像头。
- 茶水间水浸设备的 `installAddr=27楼茶水间`，监控关联记录有同样安装地址，可作为地点候选材料；尚未证明报警设备 ID 与摄像头 ID 的显式绑定。对这类地点候选如实说明依据，有歧义让用户选择，不能称作已验证的最近摄像头或精确覆盖。
- [感知 Swagger](https://ncim.577119.com/micro-api/api/perception/v2/api-docs) 的 `/videoEquipment/page` 支持 `locationElementId/locationFullName`，但当前身份返回 0 条；`/alarmRecord/page` 也为 0 条，不能用声明替代生产关联证据。
- 同 Swagger 的 `/isc/eventInfo/page` 含 `cameraIndexCode`、安装地址及坐标字段。真实查询有 13,684 条海康事件；抽样 3 条有监控点编码，坐标/地址为空。这可作为海康自身事件定位摄像头的线索，尚未证明编码到当前可播放设备的 join，更不能当成消防告警关联。
- [空间 Swagger](https://ncim.577119.com/micro-api/api/space/v2/api-docs) 有空间经纬度；未找到它与三类消防事件的直接摄像头关系。停车服务有出入口设置声明，水表/道闸业务覆盖仍留待正式文档。

**接入判断：** 优先复用已验证区域筛选、安装地址与客户消息中实际携带的监控上下文。当前不把“需要客户新建关联接口”列成已证缺口；也不宣称消防事件已自动唯一定位摄像头。
