# 物联 Agent 当前状态与剩余工作

日期：2026-09-14

## 已冻结事实

- Agent 使用客户小程序当前登录用户的身份和 token。
- 客户用户侧设备接口已经根据该用户完成上游授权过滤；Runtime 不复制用户模板、区域操作人员或设备分配逻辑。
- 测试环境固定 token 只是固定模拟一个用户，正式嵌入时继承客户小程序登录态。
- Agent 接管用户授权范围内的设备，不按“我的办公室”或某个办公场所额外隔离；办公室、楼层和房间只用于检索和展示。
- 上游设备如何注册与分配不属于 Agent 业务。Runtime 只规范化接口返回的设备、能力、状态和控制结果。
- 更多设备类型当前只保留扩展位，不要求立即接入。

## 当前完成度

- Authorized Device Scope、原子检索、候选集、能力核验、草案、确认和执行边界已经实现。
- 空调、照明、门禁完成本地确定性控制闭环；视频完成只读发现闭环。
- 会话六小时保留、手动清除、权限变化复核、跨身份隔离、执行幂等和 Agent 自然收尾已有自动化测试。
- 原生微信小程序页面已经迁移，桌面微信开发者工具当前可用于验收。

## 不是当前问题

- 不需要重新证明客户用户接口是否按用户过滤。
- 不需要第二个生产账号来重新审计客户权限系统。
- 不需要理解或复刻客户上游设备注册方式。
- 不需要现在接入环境、能源、消防等更多设备。
- 不存在“客户接口没有响应体”的结论。
