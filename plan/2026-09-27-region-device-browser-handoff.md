# 区域设备浏览交接

2026-09-27。范围为区域工作台票 10：打开设备抽屉，浏览当前用户在关注区域的设备，按类型/位置/状态分组并搜索。设备详情和设备时间轴属于票 11，本轮不提供不可用的卡片点击入口。

## 业务结果

- 工作台底部“设备”打开 90vh 抽屉，复用现有 `DeviceSheet`；目录先显示，状态随后补齐。关闭再打开会重新读取当前授权目录，避免继续展示已撤权设备。
- 目录和状态接口按当前请求身份加载 Authorized Device Scope；非本人区域返回 404。非可控视频设备仍可出现在目录中，账号级关联目录不扩大可见范围。
- 状态展示平台最后已知值及可用的上报年龄；照明粗状态没有时间戳，明确显示“上报时间未知”。状态读取失败时清空旧读数、保留目录，并显示重试入口。
- “类型 / 位置 / 状态”按冻结 P2 方案切换互斥分组；搜索按名称、类型、位置或状态匹配并高亮。设备卡复用现有产品图目录，没有新增 UI 依赖。
- 空调的指令后新鲜回读不再读写普通状态短缓存，防止过滤后的局部状态污染设备浏览和草案决策。

## 验证与边界

- Runtime 31/31 测试、typecheck、build 通过；mp 6/6 既有测试通过。仅新增区域设备 HTTP 隔离场景及空调缓存语义回归场景。
- 微信开发者工具模拟器以真实客户登录态和唯一 3200 production Runtime 验证：杨国英办公室 5 台、另一授权区域 7 台；目录、分组、搜索高亮、关闭重开及状态后补均可见。没有下发任何设备控制。
- 界面截图：[设备列表](evidence/region-device-browser/list.png)、[空调搜索](evidence/region-device-browser/search.png)。
- 冻结 P2 原型的设备抽屉作为视觉对照；微信原生字体、顶部系统栏和真实长设备名导致尺寸不同，关键布局、分组与产品卡结构已对齐。票 02 的完整时间轴保真度和真机触摸验收仍待完成。
- 真实网关状态读取耗时明显长于目录，页面显示加载中直至返回；本轮不改底层网关调用顺序。需要性能优化时以单独业务体验问题衡量，不把缩短等待冒充设备状态已知。
- 票 04 的真设备“确认 → 任务记录 → 区域时间轴”仍待一次明确确认的实际操作；本轮只做只读请求。
