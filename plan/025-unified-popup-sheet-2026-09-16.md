# 统一底部控制面板落地记录（2026-09-16）

## 背景

微信开发者工具中，原页面级自绘面板出现过遮罩点击穿透、横杆触摸不稳定、视觉层不显示但无障碍树仍有内容等问题。用户要求控制面板和全部设备面板统一，并优先使用成熟组件。

## 决策与实现

- 引入 `@dcloudio/uni-ui@1.5.12`，由官方 `uni-popup` 统一负责遮罩、层级、外部点击关闭、挂载卸载和底部进退场。
- 在 `apps/agent-miniapp/pages.json` 增加官方组件的 Easycom 映射；这是必要的，因为 `uni-popup` 还依赖 `uni-transition`，只编译外层组件会造成“逻辑树存在、视觉层不出现”。
- `DeviceSheet.vue` 保留统一的 44px 横杆命中区；WXS 只负责横杆触摸跟随、回弹和达到阈值后的关闭，不再维护遮罩手势。
- 卡片长按入口从 550ms 调整为 480ms，触点漂移容差从 10px 调整为 14px；超过容差仍取消，避免与滚动冲突。

## 验收

- `npm test --prefix apps/agent-miniapp`：33 项通过。
- `npm run test:weixin --prefix apps/agent-miniapp`：构建成功，3 项微信产物测试通过。
- 微信开发者工具：面板视觉层已正常显示，包含遮罩、横杆、标题、设备内容和底部操作；点击遮罩后面板收起且未触发底层操作；面板内部搜索入口可点击。
- 开发者工具当前无法稳定合成坐标拖拽（ScreenCaptureKit/noWindowsAvailable），横杆拖拽需在真机或可用触控窗口再做一次人工验收；这不影响组件依赖和编译产物检查。

## 后续约束

- 其他控制面板不得绕过 `DeviceSheet` 自建遮罩或关闭逻辑。
- 组件依赖变更必须同时检查编译产物的 `usingComponents`，不能只看源码或 AX 树。
