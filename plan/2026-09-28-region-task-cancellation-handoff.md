# 区域工作台删除任务交接

日期：2026-09-28。范围：区域工作台票 08；依据 `.scratch/region-workbench/issues/08-workbench-delete-task.md`、ADR 0004。

## 已接通

- `POST /api/agent/tasks/:id/cancel` 携带版本；请求时重新加载授权设备目录。任务至少一台设备可见但未覆盖全部时返回 403；版本变化或已无可取消阶段返回 409。
- 取消事务只将尚未执行的阶段标为 `cancelled/not_dispatched`。已结束阶段的逐设备事实不变，已认领执行中的阶段继续收口，不回滚动作；任务留在历史，记录取消者身份键和时间。没有执行中阶段时立即清除托管凭据，否则在执行收口后清除。
- 区域和任务详情读模型提供 `canCancel`。任务抽屉复用现有 Sheet 与微信确认框，成功后刷新详情、时间轴和日历；已取消任务保留淡化及状态文字，设备记录显示取消而非失败。

## 验证与边界

- Runtime 37/37、typecheck、build；小程序 Agent 10/10、HBuilderX 微信编译通过。HTTP 夹具场景覆盖部分授权、旧版本、已执行阶段保留和后续阶段不下发；没有新增真实网关控制。
