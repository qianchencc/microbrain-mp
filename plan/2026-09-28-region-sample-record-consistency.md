# 区域样例记录一致性交接

2026-09-28。范围仅限开发版“查看样例”的浏览路径：区域时间轴 → 设备抽屉 → 设备时间轴 → 任务详情。真实 Task API、确认和设备控制不变。

## 已接通

- 样例模式只读当前授权区域设备目录，以目录中的照明、空调 ID 和名称生成 `sample-*` Task。按 P2 的 08:30、12:00、14:00–15:30、19:00、20:00–21:30 时段展示已完成、部分完成、执行中和待执行记录；14:52 为演示时刻。任务阶段显式保存目标与演示结果，不再从标题猜目标。
- 设备抽屉继续显示真实授权目录和最后已知状态；设备时间轴的演示记录从同一批样例 Task 投影。点任一设备记录打开原任务详情，不再生成第二套互不关联的假任务。区域切换会重新定位时间轴。
- 样例不会写入 Runtime，不能取消、确认或下发设备指令。区域与设备时间轴均标注“本地演示记录”；任务详情来源同样标注演示。返回真实记录时重新请求后端。

## 验证与边界

- 唯一 3200 的只读目录在两个授权区域分别返回 7/5 台设备；两区均生成 5 条样例 Task，会议任务各关联 3 台设备，参与设备的演示记录能回到同一 Task。没有输出设备身份或调用控制接口。
- 一条公共视图模型测试保护跨区域卡、设备记录和任务详情的 Task ID/目标一致性；Agent 测试 11/11、微信小程序本地编译通过。编译仍有既有非 Agent 页面与鸿蒙兼容提示。
- 样例只是开发版的视觉与浏览演示，使用真实目录但结果完全虚构；不能替代票 04 的真实操作记录、票 14 的设备执行回读，或票 02 在相同静态数据下与冻结 P2 原型的截图对照。客户微信小程序中的样式与点击流由用户验收。
