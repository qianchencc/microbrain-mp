# 设备现态与执行结果分离交接

日期：2026-09-28。范围：客户小程序 Agent 草案卡、任务详情及区域设备抽屉；不改 Runtime 控制或任务记录。

- 执行结果仅由当次回执和执行时回读决定。草案 `ACCEPTED` 不再因后来设备现态与目标相同而显示“已达到目标”；`ALREADY_SATISFIED` 和明确 `confirmed` 仍保留对应结论。
- 当前状态只从授权状态接口读取，不再把草案执行响应中的旧 `observedStates` 覆盖到新查询结果。设备抽屉、草案卡和任务详情提供图标刷新；界面只显示必要的开关/参数、结果和失败提示，不常驻展示查询时间或无上报时间说明。
- 同一刷新入口可立即执行，也可在草案回执或可见任务阶段收口后延迟约 1 秒执行；重复触发合并，关闭页面后取消。刷新只读状态，不下发设备控制，也不修改历史回执。
- 小程序端交互与视觉验收由用户完成；代码检查限于一条结果映射回归测试、现有 Agent 测试及微信编译。真实设备的状态传播时延仍由上游决定，自动读取一次并不承诺 1 秒内看到物理变化，用户可再次手动刷新。
