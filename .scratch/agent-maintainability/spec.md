# Agent 源码可读性与深模块改进

Status: done

## 用户决定

2026-11-05：适度贴合客户的源码阅读习惯；对高耦合大文件按深模块原则改进。保留 uni-app、Vue3、JavaScript/MJS、现有路由和业务行为，沿用 ADR0008，不为外观把 components 改成 coms，不改回 Options API。

基线：`74da422`。开始时跟踪文件无未提交差异；未跟踪 `local:/` 为既有用户内容，不处理。

## 范围与实现约束

1. 任务：统一列表／详情中的周期计划状态、下一次时间、管理能力和提示；把重复的异步读取／管理协调收进既有任务领域，不让视图重新掌握请求纪元和身份规则。
2. 会话：将流式运行、恢复与确认互斥等耦合流程集中到会话深模块；页面保留输入、滚动、弹层及生命周期组合。不能只新增透传层或原样拆几个大文件。
3. 公司概览与能耗：将读取、身份切换、保留快照、历史窗口准备等协调集中到相应领域；领域入口不暴露底层文件布局。
4. 可读性：仅整理 Agent 生产范围（pages/agent 的生产 JS/MJS/Vue/样式和 apis/agent），展开模板嵌套、复杂属性、状态修改和样式声明。保留现有命名与注释，不格式化客户其他页面，不把原型或工作产物加入程序。

新增深模块通过小的领域入口提供行为；禁止返回几十个可任意操作的内部状态，让调用者重新组织流程。外部副作用通过可替换依赖接入；公共入口测试状态转换、过期读取、错误、身份切换及生命周期，而非只测试内部辅助函数。

## 必须不变

- 任务、通知和执行事实仍由后端决定；预检不是未来执行结果。
- Office／Company 身份与来源隔离；确认、取消、恢复和幂等边界不变。
- 页面收起保留输入和已有结果；不把收起等同取消后端运行。
- 读失败保留已有数据并显示真实错误，不补零、不伪造成功。
- 深链预填与历史恢复、任务列表／详情／周期管理、能耗选日和历史补块行为不变。
- 不创建真实任务、不下发设备控制、不发送通知，不切换或测试生产 Runtime。

## 预期效果

- 客户维护人员能从现有路由、Vue 模板和少量领域入口定位行为，不必先阅读一整套内部状态。
- 周期计划同一规则只在一处修改，列表与详情消费一致事实。
- 会话和能耗的关键状态转换可通过公开领域接口运行验证，视图修改不再牵动所有请求协调细节。
- 长行和多语句压缩显著减少；格式化单独提交，便于审查与回退。
- 不以文件变短、测试变多作为完成条件；以职责归属、调用者负担、回归及真实界面证据为准。

## 验证与交付

先保留行为回归，再逐域实现。最终一次全套 Agent 测试、依赖边界检查、官方微信开发构建；在真实微信同一账号检查公司概览、办公室对话恢复、任务列表／详情和能耗面板主要只读路径，证据与未验项分开记录。

改动按领域闭环提交；格式化独立提交；不包含既有无关工作内容。评估中发现的交付杂物单独记录，不在本轮未经确认删除。

## 实施结果

逻辑提交 `f67701b`：四个行为模块完成迁移。公开入口为 `createPlanManagement`／`planPresentation`、`createConversationOperations`、`createEnergyPanel`、`createCompanyOverview`；内部队列、确认集合和请求纪元不向视图暴露。任务状态规则统一，视图保留交互及展示组合，不把深模块当成“大文件分家”。

排版提交独立：固定Prettier3.6.2、Agent局部配置与限定范围命令，保留分号以满足uni-app模板事件编译；客户非Agent页面与既有原型不格式化。61个生产Vue文件中超过180字符的行，从评估基线613行降为1行（内嵌SVG字符串，未为行宽拆改其内容）；这是阅读指标，不当作架构深度或性能提升指标。

最终验证：324项Agent回归、179个源文件依赖边界、格式检查及官方微信编译通过。[真实微信记录](./evidence/REF-01/result.md)覆盖概览、列表、周期计划详情、已完成任务报告、能耗选日及重开、纯问候流式回复与会话恢复；有副作用与故障注入场景未冒充前端已验收。

预期维护效果：展示调整留在Vue；周期状态只改一处；会话确认与选区同步、能耗历史准备、概览缓存／身份失效分别在一个行为模块内修改和验证。不是承诺客户必然认可，也不是对API总入口、全部页面或全部性能问题的一次性改造。

另记交付风险：此前评估发现`0001-business-fact-storage.md`、`internal/controller/HealthController.java`、`src/main/java/ltd/qianc/iotagent/agent/internal/controller/AgentToolBridgeController.java`可进入当前归档。未在本轮删除、修改或交付；正式客户交付仍应单独检查纯源码边界。
