Status: in-progress
Blocked by: None

## 目标

按[规格](../spec.md)推进任务、会话、概览与能耗的深模块收敛，并单独整理 Agent 源码排版。遵守现有 ADR0008，保留客户技术栈与全部生产行为。

## 验收

- [x] 计划状态及管理展示规则统一；任务列表和详情不再分别实现同一判定。
- [x] 任务／会话／概览／能耗的大文件中，高耦合请求协调有明确领域归属；调用方不再重复管理被移入模块的内部状态。
- [x] 公开领域接口覆盖真实状态转换、过期响应、身份与生命周期约束。
- [ ] Agent 源码展开排版，客户其他页面不变；排版与逻辑提交分离。
- [ ] 全套 Agent 测试、依赖边界、微信开发编译及主要真实只读路径有结果；未验收项如实列明。
- [ ] 改进记录写明实测变化及预期维护效果，不以拆文件数量宣称架构改善。
