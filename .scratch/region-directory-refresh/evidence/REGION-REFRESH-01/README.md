# REGION-REFRESH-01：区域名单更新与入口恢复

## 范围

- 只改 Office 区域名单展示、刷新、顶部布局及工作台空区域反馈。不改上游办公人员、身份认证、接口地址、后端、模型或任务执行。
- Chrome 中已只读确认「26楼运营办公区」包含马云飞，办公人员记录于 2026-11-09 14:15:24 保存。该记录的账号与此前用于空目录诊断的凭据账号不同；撤回此前将空凭据直接认作马云飞、以登记字段判定其办公室配置无效的结论。不按姓名匹配、冒用账号或扩大权限。

## 改进

- 移除同一上海日直接复用区域名单的分支；已有快照只做首屏展示，每次进入和打开选择器均重读后端。
- 完整名单接纳新增、更名和移除；关注区域有效则保留，失效则选取当前名单中的区域。后台 attention 响应也同步完整名单，不再只更新旧列表中的提示。
- 空旧名单刷新期间显示读取中；成功空态和失败态均可重试。顶部和抽屉区分读取中、读取失败和确无区域。
- 顶部区域名称可收缩、裁剪，给下拉箭头和工作台保留独立空间。
- 工作台缺少关注区域时打开同一恢复抽屉，不再静默短路；会话尚未挂载时明确提示。已进入工作台后若目录确为空，则结束任务加载并显示无可用区域，不伪造零条任务。

## 工程证据

- 新增两项行为回归：同日旧空名单接纳新区域；同日更名、移除及选区有效性。改前两项失败，改后通过。测试只用虚构账号作用域及示例区域。
- 区域生命周期、视图读取及导航相关 16 项通过，含拒绝授权、换身份、迟到结果及共享消费者。
- 完整 Agent 回归 363 项通过；186 个源文件的边界检查通过。四个修改页面／组件／领域文件格式检查通过。
- HBuilderX 最终微信开发版编译成功。原有 uniCloud 未关联、巡检页面 sourcemap／Vue 导出和鸿蒙适配提示未在本轮扩修。
