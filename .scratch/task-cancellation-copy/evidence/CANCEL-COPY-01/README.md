## 实现范围

- TaskDetailContent：普通任务用“取消这项任务？”和“保留任务/确认取消”。根据后端任务状态区分未开始与已开始；电表检查点或全电表设备阶段使用电表统计文案，混合阶段不误判为纯电表任务。
- 周期发生实例：说明仅取消本次、后续周期照常执行。两个详情入口的周期操作分别标为“仅取消本次”和“取消整个周期”。
- createPlanManagement：原scope、日期、版本、权限和失效保护不变，只更新确认标题、说明及左右按钮。原生确认按钮保留四个汉字以内（取消本次/取消周期）。
- 不改取消接口与实际执行语义，不删除任务、报告或其他业务事实。
