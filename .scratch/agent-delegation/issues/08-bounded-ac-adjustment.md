# 08：有限条件调温、让行与停止闭环

Status: ready-for-agent
Parent: [完整业务委托实施规格](../spec.md)
Blocked by: 07：固定范围和有限时段的空调只读巡检；05：周期计划开关、系统停用通知与确认恢复

## What to build

完成标题所述用户闭环；复用已有能力并补齐缺口，先核对同主题旧票和候选，避免重复实施。不得把单层接线或套件数量当交付。

## Acceptance criteria

- [ ] 明确授权和有限期限内，只有开机/制冷且有效设定温度低于26℃才调至26℃；不开机/切模式/风速。
- [ ] 回读与未知诚实分类，未知不重发；参数再次改变时让行/暂停，不与其它操作反复争抢。
- [ ] 停止覆盖后续检查点及排队，在途保留；周期启停/自动失效通知复用原机制，停止不反向调温。
- [ ] 仅在具体设备/时段授权后做现场验收，不以夹具或只读结果冒充真实控制完成。

## 验证边界

沿规格的现有公开行为接口验证；稳定切片结束做一次必要检查。控制/部署需具体授权，UI先按需原型。保留用户并行WIP。
