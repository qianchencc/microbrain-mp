# 08：有界条件调温与停止

Status: ready-for-agent
Parent: [Company Agent 业务闭环实施规格](../spec.md)
Blocked by: 07：固定范围和有限时段的空调只读巡检

**Lane:** 主线控制闭环；真实设备控制必须另取得具体授权，不因票据存在自动放行。

**What to build:**

在用户明确确认的设备范围和有限时段内，只对开机、制冷且设定温度低于 26℃ 的空调把设定温度调到 26℃；系统回读结果，遇到未知、竞争操作或用户停止时如实收口。

**Acceptance criteria**

- [ ] 只有满足开机、制冷、有效设定温度低于 26℃ 的设备进入调温；关机、非制冷、未知或过期状态不下发。
- [ ] 不自动开机、不改模式/风速、不用环境站点温度代替设定温度；下发后区分受理、已核验、失败、未知和无需操作。
- [ ] 未知结果不自动重发；设备参数被其它操作改变时让行或暂停，不与其它操作反复争抢。
- [ ] 停止阻止后续检查点和排队动作，在途结果保留，不反向调温；有限期限到达后自动结束。
- [ ] 现场控制仅在具体设备、时段和服务版本授权后验收；源码/夹具/只读结果不能冒充真实控制完成。

**Delivery boundary:** 复用现有控制准备、Task/Phase、回读和收件箱；不建设通用条件规则平台或无限期自动调温。
