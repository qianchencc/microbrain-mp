# 02：定时能耗日报与原任务收件箱结果

Status: ready-for-agent
Parent: [Company Agent 业务闭环实施规格](../spec.md)
Blocked by: 01：连续只读能耗调查与即时报告

**Lane:** 主线；复用现有 Task/Phase、周期计划、报告附件和唯一任务收件箱。

**What to build:**

用户确认一条能耗日报计划后，立即看到规则、首次发生和下一次发生；到点按本次发生确定统计期间并生成日报，结果和完成/部分/失败通知回到原任务收件箱，用户可以从原入口查看、返回和继续追问。

**Acceptance criteria**

- [ ] 未确认提案不显示为已安排；确认成功后计划和首次/下次时间及时可见，统计期间与调度周期分开。
- [ ] 到点生成当次日报，按请求期间取得总量、可用比较和重点位置；缺数或失败不换旧期间、不补零、不伪装完整。
- [ ] 报告预览、依据、导出和任务通知沿现有任务入口返回，不新增报告收件箱或顶级导航。
- [ ] 重复扫描、进程恢复和迟到读取不重复落 Task、报告或通知；报告完成不提前关闭原任务区间。
- [ ] 源码回归、真实模型/只读服务和微信操作分别记录；未验收的活动服务或手机行为不得标为完成。

**Delivery boundary:** 本票不包含周报/月报、不包含外部推送，也不自动部署或控制真实设备。
