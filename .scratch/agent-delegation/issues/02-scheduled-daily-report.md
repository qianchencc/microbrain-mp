# 02：确认后可见的定时能耗日报与原收件箱结果

Status: ready-for-agent
Parent: [完整业务委托实施规格](../spec.md)
Blocked by: 01：Company 能耗调查到即时报告、依据与导出

## What to build

完成标题所述用户闭环；复用已有能力并补齐缺口，先核对同主题旧票和候选，避免重复实施。不得把单层接线或套件数量当交付。

## Acceptance criteria

- [ ] 确认后立即可见规则/首次/下次和日历安排；到点按本次期间解析既定统计要求。
- [ ] 保存该次结果与报告并经原站内收件箱打开/返回，缺数/失败如实呈现，不用旧时期补齐。
- [ ] 重复扫描/恢复不重复落任务或附件；报告完成不提前关闭原区间。

## 验证边界

沿规格的现有公开行为接口验证；稳定切片结束做一次必要检查。控制/部署需具体授权，UI先按需原型。保留用户并行WIP。
