# 04：跨范围混合控制、分阶段执行与快照管理

Status: ready-for-human
Parent: [Company Agent 业务闭环实施规格](../spec.md)
Blocked by: None（阶段目标候选只作输入；控制接回主线前需在本票内完成生命周期收口）

**Lane:** 候选接回主线；阶段目标候选不是已部署能力，真实控制仍需具体授权。

**What to build:**

用户可以委托多个楼层/区域的照明和空调混合操作，明确包含与排除范围，安排多个阶段并确认一次。系统固定每阶段成员、动作和绑定，按原快照执行；用户可以只调整未来时间、查看阶段结果并停止尚未下发的部分。普通实现取舍在本票内收口，不另建控制治理票。

**Acceptance criteria**

- [ ] 范围、排除和每阶段目标由服务器展开并核验，无法落到真实成员时先澄清；确认卡展示范围、阶段、数量和不可读项。
- [ ] 确认后固定成员、动作、统计要求和控制绑定；只改时间不重抄、不重绑、不受明细数量上限限制，版本冲突明确拒绝。
- [ ] 各阶段独立收口，已满足、已下发、已核验、未核验、未知、失败和未执行分别可见；授权/快照失效时阻止后续下发，未知不重发。
- [ ] 停止只阻止未下发点和排队动作，在途动作保留真实结果；不能把停止写成物理撤回或自动恢复设备状态。
- [ ] 既有即时控制、Office 来源隔离、Task/Phase、任务详情和收件箱继续可用；候选入口等价接通后再退出竞争选择。

**Delivery boundary:** 源码候选、离线夹具、真实模型、客户网关、微信和现场控制分别验收；本票不自动合并、部署或执行真实控制。
