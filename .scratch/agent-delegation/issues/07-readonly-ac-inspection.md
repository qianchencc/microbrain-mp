# 07：固定范围和有限时段的空调只读巡检

Status: ready-for-agent
Parent: [Company Agent 业务闭环实施规格](../spec.md)
Blocked by: None（复用现有 Company 授权、状态读取和任务结果）

**Lane:** 主线只读业务；不把本票当作真实控制授权。

**What to build:**

用户确认空调范围和有限时段后，系统按有界检查点读取状态，列出满足调温条件、无需调整和无法判断的设备，并显示实际状态时间；整个过程不下发控制。

**Acceptance criteria**

- [ ] 范围、排除和有效时段在确认后固定；检查结果能区分开机/制冷、设定温度低于 26℃、无需调整和状态未知。
- [ ] 只使用设备自身的开关、模式和设定温度事实，不用环境站点温度推断房间状态；缺少新鲜状态时明确不可判断。
- [ ] 到期后不继续检查、不产生无限任务；结果进入既有任务详情/收件箱或即时答复，能够查看本次完整结果。
- [ ] 不通过密集循环或模型反复临场决定伪造持续控制；不下发开机、模式、风速或温度修改。

**Delivery boundary:** 本票只证明只读巡检闭环；真实设备状态、微信操作和活动服务版本仍需分别验收。
