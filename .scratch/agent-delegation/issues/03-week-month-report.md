# 03：周报和自然月报按本次期间可靠产出

Status: ready-for-agent
Parent: [完整业务委托实施规格](../spec.md)
Blocked by: 02：确认后可见的定时能耗日报与原收件箱结果

## What to build

完成标题所述用户闭环；复用已有能力并补齐缺口，先核对同主题旧票和候选，避免重复实施。不得把单层接线或套件数量当交付。

## Acceptance criteria

- [ ] 周/月调度与统计期间分别显示，月报按自然月而非每30天；跨年、短月与首次时间正确。
- [ ] 每次采用本次期间及要求的比较基期，缺基期仍有部分结果，预览/导出与原收件箱一致。
- [ ] 修改未来时间不重写已保存报告，来源与固定表集保持。

## 验证边界

沿规格的现有公开行为接口验证；稳定切片结束做一次必要检查。控制/部署需具体授权，UI先按需原型。保留用户并行WIP。
