# 01：Company 能耗调查到即时报告、依据与导出

Status: ready-for-agent
Parent: [完整业务委托实施规格](../spec.md)
Blocked by: None（可从已有报告候选开始，保留并行工作）

## What to build

完成标题所述用户闭环；复用已有能力并补齐缺口，先核对同主题旧票和候选，避免重复实施。不得把单层接线或套件数量当交付。

## Acceptance criteria

- [ ] 自然语言范围/期间与明确要求准确承接；真实歧义保留已确定部分并最小澄清。
- [ ] 统计/比较后按贡献选择必要证据，保存本次采用事实，交付附件、预览、依据、引用追问及PDF/XLSX；不为即时报告建Task。
- [ ] 缺同比、错期、漏项或覆盖不足不报完整；真实零保留；全无有效本期事实无空附件。
- [ ] 整合已有S1/S2时保留开放调查、只读任务声明、完整授权和原UI；Excel/微信打开分别验收。

## 验证边界

沿规格的现有公开行为接口验证；稳定切片结束做一次必要检查。控制/部署需具体授权，UI先按需原型。保留用户并行WIP。
