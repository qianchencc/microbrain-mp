# 05：周期计划开关、系统停用通知与确认恢复

Status: ready-for-agent
Parent: [完整业务委托实施规格](../spec.md)
Blocked by: 04：跨区域分阶段控制与保快照改时、停止（自动停用所需本次停止语义）

## What to build

完成标题所述用户闭环；复用已有能力并补齐缺口，先核对同主题旧票和候选，避免重复实施。不得把单层接线或套件数量当交付。

## Acceptance criteria

- [ ] 先完成最小交互原型；现有周期列表/详情展示同一启用开关，权限/来源和返回关系保持。
- [ ] 用户关闭只停未来，不误称本次已停；启用核验/确认后才开启，取消/失败原状，重复点击/版本冲突不重复执行。
- [ ] 明确拒绝/撤权/绑定变化使计划未启用并停止本次后续；普通超时或局部回读失败不等同此事件。
- [ ] 自动停用结果在原收件箱向创建者通知一次，重扫/重启不重报；全撤权仍可看最小停用通知，明细/附件不越权。
- [ ] 恢复网络/权限不自动启用，重新确认后只从未来发生开始，不补旧点、不更换原绑定或重发未知。

## 验证边界

沿规格的现有公开行为接口验证；稳定切片结束做一次必要检查。控制/部署需具体授权，UI先按需原型。保留用户并行WIP。

`prototype/recurring-enable-state` / `c4e0e91` 已保存单文件内存状态原型，入口及已验边界见[原型回传](../../../plan/2026-10-20-agent-delegation-design-handoff.md)。自动走查不等于用户体验/原生验收；复用原列表/详情样式，不合并原型页面到生产路由。
