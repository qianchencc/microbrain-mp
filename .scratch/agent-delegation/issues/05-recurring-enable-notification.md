# 05：周期计划任务管理、启停与失效通知

Status: ready-for-human
Parent: [Company Agent 业务闭环实施规格](../spec.md)
Blocked by: None（现有计划手动启停可独立开始；控制失效后的后续停止分支依赖 04，未验收前整票不记完成）

**Lane:** 主线任务管理；周期启用/停用归现有计划列表和详情，不新建管理页或治理平台。

**What to build:**

用户可以在现有周期计划列表或详情中启用、停用计划。手动停用只影响未来发生；明确撤权、执行身份拒绝或控制绑定变化时，计划进入未启用，并在原任务收件箱留下一次说明原因和本次结果的通知。重新启用必须重新核验并确认。

**Acceptance criteria**

- [ ] 列表和详情显示同一个已启用/未启用状态，手动关闭成功后未来不再发生；当前正在执行的本次任务仍单独展示，不假称被撤回。
- [ ] 启用前核验当前完整范围、原快照/绑定、期限和版本，展示下一次发生并经现有确认入口确认；取消、失败或冲突保持未启用。
- [ ] 明确撤权、身份拒绝或绑定变化使计划未启用，并停止本次尚未下发点；普通超时、局部设备失败或回读失败不自动停整条计划。
- [ ] 自动停用结果只向创建者写入一次原任务收件箱通知，重扫/重启不重复；通知不越过当前设备授权展示明细。
- [ ] 网络/权限恢复不会自动启用，不补旧发生、不重发未知；重新确认后只从未来发生继续。

**Delivery boundary:** 开关属于任务管理闭环，不单独建票；通知仅限站内任务收件箱；真实服务发布和控制仍需具体授权。
