# 06：三类告警统计与已有摄像头线索联查

Status: ready-for-human
Parent: [Company Agent 业务闭环实施规格](../spec.md)
Blocked by: None（独立只读业务，不等待周/月报或空调控制）

**Lane:** 主线只读业务；已有摄像头能力只作为记录核查入口。

**What to build:**

用户可以按明确的上海时间窗口查看烟感、燃气、水浸三类告警的记录数、涉及设备数和有效明细；需要继续核查时，可以从记录进入当前设备资料和已有摄像头直播/回放线索，再返回原对话或任务结果。

**Acceptance criteria**

- [ ] 服务器负责分页、稳定记录身份去重和分类统计；三类分别展示记录数、设备数、明细及统计窗口。
- [ ] 某类读取失败、窗口不完整或设备范围不全时保留其它有效事实并说明，不报零、不报全量；没有记录不等同于已恢复或安全。
- [ ] 定时统计可以沿现有 Task/Phase 和唯一任务收件箱交付，不新增告警处置平台或外部推送。
- [ ] 追问可查看记录时的位置和当前设备资料，选择已有监控候选并进入直播/回放；历史名称、当前位置和录像入口保持语义区分。
- [ ] 不宣称已经看过录像、告警已恢复或已完成消防处置；视频理解和自动联动留在后续范围。

**Delivery boundary:** 只读数据、摄像头取流、微信操作和活动服务版本分开验收；本票不产生设备控制授权。

## 2026-10-20 本轮源码交回

主线已接三类分类/设备统计、部分结果和原摄像头线索；每日汇总按计划at的上海前一自然日，不用滚动24小时冒充昨日。 按用户要求未新增/运行测试、双审或探针；类型检查、构建与微信编译结果及未验边界见[总交接](../../../plan/2026-10-20-agent-delegation-delivery-handoff.md)。源码完成与活动服务/客户/微信/现场验收分开，未执行的验收条件不勾选。
