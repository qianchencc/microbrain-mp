# 06：每日告警统计与基于记录的监控核查

Status: ready-for-agent
Parent: [完整业务委托实施规格](../spec.md)
Blocked by: None（复用现有台账、Task与视频能力，不依赖控制或自然月报）

## What to build

完成标题所述用户闭环；复用已有能力并补齐缺口，先核对同主题旧票和候选，避免重复实施。不得把单层接线或套件数量当交付。

## Acceptance criteria

- [ ] 明确上海窗口，服务器分页/去重，烟感/燃气/水浸分别给记录数与设备数；失败/未读不填零。
- [ ] 定时结果沿原Task/站内收件箱交付；部分有效事实保留，不另建告警处置平台。
- [ ] 追问可读原记录、核对当前位置、选择真实摄像头/直播回放；历史名称不冒充当前/事发位置，不称已恢复或已看录像。

## 验证边界

沿规格的现有公开行为接口验证；稳定切片结束做一次必要检查。控制/部署需具体授权，UI先按需原型。保留用户并行WIP。
