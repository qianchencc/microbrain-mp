# CALENDAR-CARD-01：任务卡片右侧裁切

2026-11-10。用户原截图显示公司任务安排／日历中每张卡片右边框与圆角被裁切。

## 修复

`TaskCalendarView.vue` 的 `.calendar-task` 同时设置 `width: 100%` 和左右各16px外边距，外边距不包含在 border-box 内，卡片超出父容器。删除该 width 声明，由块级 flex 卡片自动计算可用宽度。保留既有16px边距、完整标题换行、按钮语义与点击行为；不改任务数据、执行状态或后端。
