# 完整业务委托的交付与自主推进界限

## Question

在观察、调查、即时操作、未来委托、报告交付和已有客户需求之间，哪些完整用户结果属于本轮目标，何时算完成/部分/待补充，系统可自行推进哪些有证据的步骤，何时必须让用户选择或确认？

## Context

用户已认可终点不是完善控制任务工具链，而是完整业务委托。[目标/现状对照](../../../docs/research/2026-10-20-agent-delegation-current-state.md) 的业务族用于讨论，不是七项同时实施承诺。已有明确报告、站内通知和有限巡检需求继续保留来源，不把旧首条场景限制复制成全局规则。

## Resolution needed

通过真实业务目标和必要反例收口用户可见交付、自主只读调查、必要澄清、控制确认、成果与后续追问/修改/停止的界限；保留主动调查能力而不新增未授权副作用。普通实现细节由代理处理，不要求用户设计字段或重讲代码；不冻结工具名/schema，也不在这里实施。

## Comments

- 2026-10-20：目的地方向已获认可；具体完整交付与自主推进界限仍开放。建图阶段不代用户回答。
- 2026-10-20：用户明确授权常规设计自行推理，以灵活、可靠、轻便和快速交付必要能力为准，直到出现真正重要的产品/风险/授权决定再询问；减少文档分裂、频繁双审及测试。本票已认领，先按已有业务范围和安全约束收口，不重新询问已定原则。

## Resolution — 2026-10-20

依据本轮用户“常规设计自行推理，继续至必要重要决策”的明确授权收口。以下是设计决定，不是新增业务已实现；不新增通用委托对象或统一状态机。

### 完整交付按请求判断

| 委托 | 最低可交付结果 | 不能作为完成证据 |
| --- | --- | --- |
| 查询/调查 | 回答所问范围与期间，给出实际取得事实及必要依据；不能确定的原因明确保留，允许后续追问 | 工具调用成功、模型正常收尾、只列候选 |
| 即时报告 | 本次明确要求的事实、比较与覆盖逐项有结果；有效内容形成现有附件，无有效本期事实则说明而不造附件 | 保存附件成功、标题写了“同比环比” |
| 即时控制 | 确认的目标对应实际下发/跳过/拒绝/回读结果，区分已受理与已核验 | HTTP 200、无时间戳的状态、模型“已完成” |
| 未来任务/周期 | 确认后登记并可见首次/下次安排；到点按固定快照执行；结果和附件回到原任务/站内收件箱 | 待确认卡、未来虚拟投影、计划已创建 |
| 调整/停止 | 明确被改变的对象、本次或整个周期、开始生效时间及未受影响的历史/在途结果 | 仅停止对话生成、只关周期而声称本次也停止 |

对话已答复、计划已登记、一次执行已结束、业务目标已达成分别表达。保留现有各业务状态；不新增 requested/accepted/completed 的平行持久化体系。

### 自主推进与必要澄清

- 在当前来源和授权内，可自主读取目录/状态/历史，解析有唯一依据的简称，按已取得贡献查具体表、按已有记录核对当前设备资料与摄像头候选。不逐次请求只读许可，不规定固定工具脚本。
- 查询扩大只能寻找线索，不能扩大最终控制/计量范围；候选只是候选。多个合理对象、包含/排除无法落到真实成员、时间或“仅本次/以后全部”影响真实安排且无法从上下文唯一确定时，提出一个最小选择，保留已确定部分。
- 调查继续必须有与当前问题相关的新证据方向；相同查询、无新证据或现有运行预算耗尽时交付已有事实和未决原因，不加新重试平台、额外通用预算或臆造调用次数阈值。
- 所需事实区分已取得、缺数/不可比、读取失败、不支持、尚未取得。后四类不能称完整成功；有有效部分就交付部分，真实零保留，空业务区块省略但缺口不能隐藏。
- 证据只能支持关联或数值贡献时，不自动上升为因果、浪费、故障、节能或安全结论。告警台账不证明事故或恢复，录像入口不证明看过画面。

### 确认与后续

- 查询、解释保存事实、即时报告和导出不强制建 Task 或增加审批；实际操作、未来执行和计划变更沿既有明确确认入口。引用/用户选地点不是执行许可。
- 未来目标保留当前已满足成员，到期重新判断；即时已满足可返回事实而不生成多余操作。预检不是未来跳过依据。
- 改时间不得改设备成员、动作、控制绑定、统计要求或核验口径；变目标重新准备差异并确认。已执行结果/已存报告不回写，正在执行部分用旧快照收口。
- 解释原报告沿保存事实，改变范围/期间形成新查询或新附件；当前访问仍重核权限。唯一任务收件箱和原有附件预览/返回保持不变，无外部推送。
- 停用周期只阻止未来发生；停止本次阻止尚未下发点和排队动作，已在途如实收口，不能承诺撤回或自动恢复设备状态。用户只说“停掉”且对象作用域不唯一时必须澄清。
- 原夜间收口“授权/快照失效阻断本次后续下发”继续有效，不重新询问。周期计划未来发生是否自动暂停/恢复属于独立风险选择，不在本票暗中决定。

常规决定由用户本轮授权覆盖；没有据此取得联网试跑、候选合并、部署或真实设备控制授权。既有空调安全默认与报告需求继续沿[需求路线](../../../plan/2026-10-20-company-automation-requirements-and-roadmap.md)，不另开竞争需求清单。
