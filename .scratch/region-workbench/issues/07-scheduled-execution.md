# 07 — 到点执行

**Spec:** `.scratch/region-workbench/spec.md`（“Runtime：执行器”）
**领域:** ADR 0004 执行规则 1–3、6、7；`CONTEXT.md` 任务执行、错过的阶段、执行身份
**仓库:** iot-agent-runtime + mp

**What to build:** 已安排的任务在阶段时刻自动执行：以创建者身份读取阶段全部设备，只对未达标设备下发并回读，已达标记为成功的无操作。两个阶段各自独立执行。时间轴卡片、任务抽屉和对话中的任务卡都能看到执行中、已完成、部分完成、失败、已错过的状态与逐设备结果。

**Blocked by:** 01, 06

**Status:** ready-for-agent

- [ ] 构建出的 Runtime 暴露“执行一次到期扫描”方法；生产按默认 15 秒周期调用
- [ ] 扫描以 CAS 认领到期 `pending` 阶段；到期超过 10 分钟的置 `missed` 不执行；确认时首阶段已到期但在窗口内则立即执行
- [ ] 执行：解密凭据 → 以创建者身份加载授权设备范围 → 缺失或越权设备记 `missing` → 其余交给 01 的执行模块 → 写逐设备结果 → 汇总阶段与任务状态
- [ ] 上游 401/授权不可用：阶段 `failed`，原因“创建者登录已失效”
- [ ] 任务终态即删除托管凭据；启动时残留 `executing` 阶段置 `interrupted`，不补跑
- [ ] 前一阶段失败不影响后一阶段执行
- [ ] 视图模型与页面呈现执行中（玉绿）、部分完成（黄铜）、失败、已错过、创建者登录已失效
- [ ] Runtime 测试（注入 `now` + 扫描方法 + 网关夹具）：已达标无操作、按需下发与核验、阶段独立、补执行窗口内外、确认后立即执行、凭据失效、终态删除凭据（再次扫描不执行）、启动自愈、越权设备 missing
