# 11 — 设备时间轴与设备日历

**Spec:** `.scratch/region-workbench/spec.md`（“查询接口”“页面与组件”）
**领域:** `CONTEXT.md` 设备时间轴
**仓库:** iot-agent-runtime + mp

**What to build:** 用户在设备抽屉中点一台设备，进入它自己的时间轴：同一套 B6 几何，内容是这台设备在各任务阶段中的记录——来源（定时/即时）、目标、结果、发起人。设备时间轴有一个更轻的日历，只标出这台设备有记录的日期，并从区域时间轴当前所看的日期打开。点某条记录打开所属任务的抽屉。

**Blocked by:** 05, 10

**Status:** ready-for-agent

- [ ] `GET /api/agent/devices/:deviceId/timeline?date=` 与 `.../calendar?from=&to=`：从任务阶段设备记录投影，不另建来源；设备不在授权范围时 404
- [ ] 设备时间轴复用 02 的几何与渲染组件，记录样式与区域卡片可区分
- [ ] 设备日历属于设备时间轴组件；进入时沿用区域时间轴日期
- [ ] 点记录打开 05 的任务抽屉
- [ ] Runtime 用少量公开接口场景保护投影与隔离；记录文案、日期沿用与跳转在微信操作流程中验收
