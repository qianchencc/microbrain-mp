# 05 — 任务抽屉与区域日历

**Spec:** `.scratch/region-workbench/spec.md`（“查询接口”“页面与组件”）
**仓库:** iot-agent-runtime + mp

**What to build:** 用户点区域时间轴上的任务卡，弹出按阶段排版的任务抽屉：每个阶段的时刻、状态，阶段内每台设备的目标状态与执行结果（已达标无操作、已下发并核验、未确认、失败原因等），以及创建者、创建时间和来源会话。区域时间轴自带日历，标出有任务的日期，可回看任意过去日期、向后最多 7 天，切换日期后时间轴随之刷新。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] `GET /api/agent/tasks/:id` 返回逐阶段逐设备的目标与结果、来源；可见性同时间轴
- [ ] `GET /api/agent/regions/:regionId/calendar?from=&to=` 返回有任务的日期与有异常的日期
- [ ] 任务抽屉复用 `DeviceSheet` 底座，保持根节点常驻、关闭禁用指针、拖拽跟手与回弹
- [ ] 抽屉为只读（删除见 08）；阶段视图与结果文案由视图模型产出，在微信操作流程中验收
- [ ] 日历属于区域时间轴组件而非页面；前向上限 7 天
- [ ] 页面参数中的日期被尊重，便于后续从对话与设备时间轴跳入
