**Blocked by:** 07, 08, 09, 11, 12, 13

**Status:** ready-for-human

- [ ] 按 runtime AGENTS.md 正确启动（先 build，身份只从 `var/agent-identity.json` 注入，配置任务凭据密钥）

- [ ] 在工作台删除一个未开始的任务，在 Agent 中取消另一个，两者都显示为已取消且未执行

- [ ] 结论、截图与遗留问题记入 Comments；新问题另开票
