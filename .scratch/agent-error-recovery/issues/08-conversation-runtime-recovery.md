# 08: 对话启动与模型中断后安全续接原委托

**What to build:** 模型启动前目录读取短暂失败、模型连接中断或会话恢复时，系统尽可能继续同一委托，保留已取得结果；用户停止/新消息后旧恢复不再运行。

**Blocked by:** 01 — 同会话恢复身份与持久化；02 — 读取重试和有限预算。

**Status:** implemented-and-verified

## 开工与范围

读 [规格](../spec.md)、[执行地图](../execution.md)、[验收方案](../acceptance.md)。覆盖现有模型开始前的目录/引用预读、模型连接及合法上下文续接；已有租约写恢复和断流轮询作为相容性验收，不重写持久化、不追查 30 秒事件循环停顿。

## 实现约束

- 预读瞬时失败由宿主安全重试；授权失败保留拒绝。无授权目录时不能假装工具有完整设备范围。
- 首次模型连接及工具后失败按合法消息序列、已完成工具事实和副作用状态判断是否可续接；恢复只追加剩余推理，不从用户问题重跑全轮。
- 存储无法恢复、非法/不完整协议、预算耗尽等由程序诚实收尾；保留已保存成果及缺口，不依赖另一个不可用模型解释自己。
- 断流继续由服务端完成和持久化；重开只恢复，不发起第二轮；停止取消后续等待，旧恢复不能覆盖新消息或跨身份。

## 验收

- [ ] A10：目录首次失败后同一消息完成；首次模型连接失败符合现有有限重试策略。
- [ ] 已有工具结果后模型失败可安全续接时不重复工具/成果；不合法上下文则保留已成成果并准确结束。
- [ ] 租约过期恢复后同会话可继续且历史完整；不能通过重新创建会话丢历史绕过。
- [ ] A11：显式停止、连续新消息、断网重连、页面重开、换身份/source 均没有重复 run 或迟到覆盖。
- [ ] staging 用真实模型/网关，受控注入预读及连接失败；前端可见操作验证恢复。移动网络真机证据单独记录，环境不足不以模拟器冒充。

## 验证与交付

沿公开对话/取消/恢复与 NDJSON 验证，不断言模型私有 messages 或内部 lease 标志；需要校验历史时从公开恢复和下一轮行为进入。保留请求计数与结果关联，类型/构建、回归与真实证据随票交付。
